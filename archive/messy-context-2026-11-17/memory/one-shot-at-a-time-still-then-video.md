**Hand over one prompt at a time, never a batch.** Deliver one still prompt and stop; the next
one comes when that still is accepted.

**Order changed 2026-09-28 (Jack, Camping music video v2 "Signs"):** *"make the images first, then
make the videos."* Work the whole shot list as stills first, still one prompt per turn, and only
then go back and write each shot's video prompt. The older order (still, then that shot's video,
then the next shot) is superseded for this film. Ask before assuming it for a new film.

**Why:** Jack generates in Flow by hand as prompts arrive, so a batch leaves him holding prompts
he can't act on. Stills-first lets the whole film's look be judged and matched before any video
credit is spent. Each video prompt is still written against its own accepted still.

**How to apply:** one still prompt per turn, in shot order. When all stills are accepted, start
the video prompts, one per turn. Related: [[always-new-prompt-never-edit-an-image]],
[[flow-hand-driven-not-automated]].

# Fact check: Defence, Foreign, Energy

2026-11-05. Fact-checker pass over `ministers/02-foreign.md`, `ministers/05-defence.md`,
`ministers/09-energy-climate.md`, the matching rows of `absorb/landscape.md`, and the README §7 "fact
gate" items in this scope (NATO resilience; generator levy terms). 17 web searches, 1 page fetch.

**Grades.** A = primary (gov.uk, Ofgem, Parliament, legislation.gov.uk, UN, NCSC). B = reputable
secondary (major outlet, law firm, Commons Library, Full Fact, trade press). C = weak (aggregator,
blog, single unclear source).
**"(KN)"** after a source means the fact was confirmed from knowledge held before this session (to
June 2026) against a stable reference URL that was **not opened today**. It is good enough for the
cabinet's background, and should be opened once before it goes on a public page.
**Verdicts.** TRUE · FALSE · OUTDATED (was true, the world moved) · UNVERIFIED (no adequate source
found). PARTLY is used where the core is right but the wording overreaches; the fix is in "Must
change".

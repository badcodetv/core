# Shape 03: The logic said plainly

Each character works the argument out loud in short steps, so the audience can follow it like a sum. In Dialogue 1 the sum is: it only sends data, he is only data, it runs on the hundred of them, so they go to sleep and he goes back. Sandra and Derek each ask the next obvious question and Maddie answers it flatly. In Dialogue 2 Sandra states the sum's result herself ("nothing after") and spends her last words on the old row.

## Dialogue 1: The wafer: what it costs

| Speaker | Line | Est. s |
| --- | --- | --- |
| DEREK | What is it? | 1.0 |
| MADDIE | It's the time machine. It can only send data back. Not people. [beat] And he's just data. | 5.0 |
| DEREK | So what does it run on? | 1.8 |
| MADDIE | You. All hundred of you, all at once. | 2.4 |
| SANDRA | And when it's had us? | 1.5 |
| MADDIE | You go to sleep, love. And you don't wake up. Only he goes back. | 4.0 |
| SANDRA | Will it hurt? | 1.0 |
| MADDIE | Not much. Like nodding off. He says less than the last five years. | 4.0 |
| DEREK | [flat] Right then. | 1.2 |
| **Total** | | **21.9** |

**Why it works.** A chain of cause and effect, each link one short sentence, so a half-listening viewer still gets the bargain. Maddie only answers, which is her care register. "You go to sleep, love" is plain and warm. The joke comes from Maddie relaying the boss ("he says").

**Cuts from current.** "It'll send all of you back..." and "it'll send him too, so he can help you avoid it".

**Risk.** A lot of exposition in about 22 s; reads like a briefing. If TTS rushes the pauses, "you don't wake up" will not land. "He's just data" could sound cold. "Only he goes back" repeats the point; may need to lose "Not people".

**Protected lines.** "What is it?" survives verbatim as the opener.

## Dialogue 2: The goodbye: two hands

| Speaker | Line | Est. s |
| --- | --- | --- |
| SANDRA | So that's it, then. Nothing after. | 2.3 |
| DEREK | That's it, love. | 1.2 |
| SANDRA | Then I get the last word. [beat] Seat down. | 2.8 |
| DEREK | [quietly] ...Seat down. | 1.5 |
| **Total** | | **7.8** |

**Why it works.** Sandra says the logic out loud ("nothing after"), so there is no implied reunion, then turns it into the row. The last word is the one thing thirty years never gave her. Derek concedes for the first and last time.

**Cuts from current.** "Hang out with non-grumpy Derek" and "Yes, love. Are you ready for this?".

**Risk.** "Nothing after" is the most explicit line in the scene, blunt next to Dialogue 1's euphemisms. "Last word" may be heard as triumph. Depends on the seat row being set up. Derek's whisper is easy for TTS to flatten.

**Protected lines.** None.

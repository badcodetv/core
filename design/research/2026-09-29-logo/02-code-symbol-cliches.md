# 02 — Code-symbol clichés, and the computer symbols ordinary people know

*Research brief, 2026-09-29. One Sonnet agent, 8 web searches (cap 8). Raw research, not house policy — the ruled layer is [`direction.md`](./direction.md) once Kai rules on it.*

**Evidence grades:** *verified* = the agent fetched a page that says it · *secondary* = a search snippet or secondary source said it · *(unverified)* = recalled from the model's own memory, not checked. The agent could not see images: every description of a logo comes from text.

## Headline

Code punctuation is a saturated, literal-pun lane (the 2012 curly-brace gallery is almost all companies with "code" in the name, which is exactly the current BadCode logo). The ownerless, universally understood vocabulary is FAILURE symbols (dead pixel, replacement character, error screens, standby light), because "bad code" literally means "output that broke", and a lone red fault-light gives the Terminator/HAL menace without copying anyone's eye.

## Findings

- **[verified]** Curly-brace logos are an old and literal genre. A 2012 Designbeep gallery of 23 'clever' brace logos is almost entirely brands with 'code' in the name (Grammacode, ancode, Moon Code, Brain Code, Microcode, HealthCode, CodeLock, NewCode Media, Codebrella, Code Bull, ButterflyCode, Code Cloud, Codenerds, iKODE, Code Circle, codelab and others). The device is a pun on the name (a brace standing in for C), which is what the current BadCode mark does. It was already a genre 14 years ago. — <https://designbeep.com/2012/12/13/23-logo-designs-with-clever-use-of-curly-bracketsbraces/>
- **[secondary]** Stock-image volume shows saturation. A Shutterstock search page reports 6,414 'bracket logos' and 40,371 'bracket symbols'. Adobe Stock sells ready-made 'coding symbols' icon sets bundling angle brackets, code slash, curly braces, equals sign and semicolon, so these glyphs are commodity clip-art vocabulary. (Counts are from search-result page titles, not a study.) — <https://www.shutterstock.com/search/bracket-logos>
- **[verified]** LogoLounge 2024 Logo Trend Report ('Pixel Drop'): pixel art in logos was so overused in the early digital era that 'using pixel art for a tech client became frowned upon, a tired cliché and industry punchline'. It is now creeping back as a 'bit player' inside wordmarks rather than the whole mark. So pixel/8-bit is both burnt and mid-revival; a pixel as a small accent is safe, a pixel-font wordmark is not. — <https://www.logolounge.com/trend/2024-logo-trend-report>
- **[secondary]** The terminal prompt (chevron plus underscore, or a block cursor in a rounded black window) is a stock icon in Font Awesome and Streamline's free terminal icons. Windows Terminal ships underscore, bar, filled-box and empty-box cursor shapes. Cursor (the AI editor) went with a cube mark in its brand guidelines, avoiding the prompt. The prompt is a generic UI icon meaning 'developer tool' and nobody can own it. — <https://cursor.com/brand>
- **[secondary]** I could not find a trade-press piece (Brand New, LogoLounge) that explicitly names braces or angle brackets as the top tech-logo cliché. The evidence for saturation is indirect: stock volumes, the 2012 gallery, and generic AI-logo prompt pages that treat '< / >' plus monospace as the default developer-tool logo. Say 'saturated' with confidence; don't claim a named trend report calls it dead.
- **[verified]** Replacement character U+FFFD (black diamond with a question mark): shown when text can't be decoded, e.g. a Windows-1252 email opened as UTF-8. Wikipedia lists no logo, art or branding use, and a targeted search for a brand or label built on it found none. It is ownerless. Universality is moderate: most people have seen it in a garbled email or web page, but few know its name, and modern systems increasingly show an empty box (.notdef 'tofu') instead. — <https://en.wikipedia.org/wiki/Replacement_character>
- **[verified]** The standby/power symbol (line inside a broken circle, IEC 60417-5009, in the 1973 edition of the standard) is globally understood. The lines from Wikipedia: the switch 'does not fully disconnect the device', and its exact meaning 'may be unclear until the control is tried'. It has been used by Gateway (c.2002), Staples easytech, Exelon, on Garbage album art and on TV-series logos. It is universal but crowded and reads as 'power button'. Its story fits BadCode perfectly: a thing that is not off, only waiting. — <https://en.wikipedia.org/wiki/Power_symbol>
- **[verified]** Windows Blue Screen of Death: recognised worldwide (Gates's Windows 98 crash at COMDEX 1998). The sad-face emoticon was added in Windows 8. Microsoft changed the screen to black (build 26120.3653, 2025), ending about four decades of blue. Owned in practice by Microsoft, so a direct copy points at them, but 'the machine has stopped and is sorry' is a strong emotional register. — <https://en.wikipedia.org/wiki/Blue_screen_of_death>
- **[verified]** Dead and stuck pixels: a pixel that stays 'always on' (bright) or never lights (black); recognisable to ordinary users as a dot that ignores the picture. No brand owns it. As a logo it fails at small sizes because it is defined by being tiny, but it is the purest 'a fault in your own screen' image, and a square fault-point distinguishes it from every round red-dot mark. — <https://en.wikipedia.org/wiki/Stuck_pixel>
- **[verified]** BBC Test Card F: first broadcast 2 July 1967 (first UK colour test card), girl Carole Hersee with clown doll Bubbles, daytime use until 1983, phased out around 1997-99. Heavily parodied (Gorillaz and Madness videos, Life on Mars, Top Gear) and licensed as wall clocks, bedsheets, clothing. Deeply British and beloved, so it carries nostalgia, not menace, and a TikTok-age viewer may not know it. Caution: the Wikipedia page also claims Radiohead's Kid A artwork uses it, but the Kid A page I fetched describes mountains and a red pool, so treat that claim as doubtful. — <https://en.wikipedia.org/wiki/Test_Card_F>
- **[verified]** Loading spinner ('throbber'): Netscape's animated N gave it the name; modern spinners are wheels of 8-12 radial lines; text versions cycle | / - \ (1970s UNIX). Wikipedia says no major company uses a throbber as an official logo. Universal as an experience, but as a static mark it is indistinguishable from a sun, an aperture or a generic loader. — <https://en.wikipedia.org/wiki/Throbber>
- **[verified]** The red dot is cultural common property but with owners. HAL 9000 is 'a camera lens containing a red and yellow dot' (Fisheye Nikkor 8mm prop). Apple recreated it in a 1999 Y2K web ad. Leica has used a bold red circle with white lettering as its official logo since 1999, based on a 1970s quality mark. A red circle means 'camera company' to photographers and 'HAL' to everyone else, so a plain red dot is neither original nor safe. — <https://en.wikipedia.org/wiki/HAL_9000>

## Precedents

- **Designbeep's 23 curly-brace logos (2012)** — Grammacode, ancode, Moon Code, Brain Code, Microcode, HealthCode, CodeLock, NewCode Media, Codebrella, Code Bull, ButterflyCode, Code Cloud, Codenerds, iKODE, Code Circle, codelab and others; mostly a brace standing in for a letter or wrapping an object, in companies with 'code' in the name. **Lesson:** Brace-as-letter for a name containing 'code' was already an established, punny genre in 2012. It is exactly BadCode's current move, so the cliché worry is justified. — <https://designbeep.com/2012/12/13/23-logo-designs-with-clever-use-of-curly-bracketsbraces/>
- **Cursor (AI code editor)** — Cube mark in 2D and 2.5D, horizontal lockup preferred, with a separate wordmark, per its brand page. **Lesson:** A current developer-tool brand chose a solid non-code shape over the prompt or cursor glyph even though its name is the text cursor. The prompt lane is so crowded that even the name did not make them use it. — <https://cursor.com/brand>
- **Windows Terminal / generic terminal icon** — Rounded black window with a white chevron prompt and underscore (the stock 'terminal' icon in Font Awesome and Streamline). From my memory of the product icon; the sources describe the generic icon. **Lesson:** The prompt-and-cursor is a stock UI glyph. A brand using it inherits the meaning 'developer tool', which is the opposite of unmistakable. — <https://fontawesome.com/icons/classic/solid/terminal>
- **Gateway (c.2002) and Garbage's album art** — Both used the standby symbol (a line inside a broken circle) as a brand or artwork device, according to Wikipedia's power-symbol article. **Lesson:** The power symbol as branding is not new, so it must be altered (colour, container, a second idea) to be ours. It proves ordinary people read it instantly, including on music artwork. — <https://en.wikipedia.org/wiki/Power_symbol>
- **HAL 9000's red-and-yellow lens** — A camera lens with a red and yellow dot; Apple recreated it in a 1999 Y2K web ad. **Lesson:** The red-dot machine eye is a shared cultural shorthand that even Apple borrowed as a joke. Any red-dot BadCode mark will be read against HAL, so the differentiator has to be shape, not just the dot. — <https://en.wikipedia.org/wiki/HAL_9000>
- **Leica red dot** — A bold red circle with white lettering, the official Leica company logo since 1999, derived from a 1970s Leitz quality mark. **Lesson:** A plain red circle with white type is already a famous corporate logo in photography. The dot is claimed at the brand level, another reason to avoid a bare round one. — <https://1000logos.net/leica-logo/>
- **Netscape's N throbber** — An animated blue N that pulsed during page loads, which gave 'throbber' its name. **Lesson:** The rare case of a loading indicator becoming a brand asset, and it worked because it was the brand's own letter animating. Wikipedia says no major company uses a throbber as an official logo. — <https://en.wikipedia.org/wiki/Throbber>
- **BBC Test Card F merchandise** — The girl-and-clown test card, licensed onto wall clocks, bedsheets, wristwatches and clothing; parodied in Gorillaz and Madness videos. **Lesson:** A 'nothing is broadcasting' image can sustain a merch line, so a failure symbol can be a lovable brand asset. But the affection is nostalgic and British, which softens threat. — <https://en.wikipedia.org/wiki/Test_Card_F>
- **Windows Blue Screen of Death (sad-face era)** — Full-screen solid colour with a large ':(' and a stop message, blue from the early years and black from 2025. **Lesson:** Proof that a totally minimal 'the machine failed' screen is recognised globally. But it is Microsoft's, so we can borrow the register (one colour field, one small face) but not the artefact. — <https://en.wikipedia.org/wiki/Blue_screen_of_death>
- **Sad Mac icon (Susan Kare, Apple)** — Pixel-drawn Macintosh with X eyes and a frown shown on failed startup. From memory, not fetched. **Lesson:** A companion failure icon that became an object of affection: users love a machine that admits it broke. It shows failure symbols work best when they have a face; BadCode wants the opposite, a failure icon that has no apology.

## Clichés to avoid

- Curly brace { } standing in for the C (the current mark, and a 2012-vintage genre)
- </> angle brackets with slash
- Terminal prompt '>_' or block cursor in a rounded black window
- Binary 0s and 1s, falling green Matrix code
- Pixel-font wordmark or full 8-bit pixel treatment (LogoLounge calls it a punchline)
- RGB-split glitch effect on the wordmark
- Circuit-board brain or head silhouette
- A plain red circle or HAL eye (already owned by HAL culture, Leica, Target-style bullseyes)
- The power-button symbol used as a bare icon
- Semicolon or hash as a cute code pun

## Risks

- **(medium)** Failure symbols read as 'this website is broken', not 'this AI is threatening' — The error dialog, BSOD and broken-image icon are comic-embarrassing, not menacing. Menace has to come from restraint (one red light, black field, stillness), not from the symbol itself.
- **(high)** A tiny single-point mark (dead pixel, LED) disappears at avatar and favicon sizes — A 1-pixel or 1-dot mark is nothing at 16px. The dot needs a container (a black tile, a frame or a ring) to survive as a TikTok or Spotify avatar.
- **(high)** Lone red dot resembles HAL, Leica, a REC light or a notification badge — Any plain red dot on black will be read as HAL or as a record/notification light. The mark needs one distinguishing shape decision (square, broken ring, diamond) so it is recognisably ours.
- **(medium)** Symbols recognised only by older or technical viewers — Test card and the replacement character are best known to people over 35 or to text-encoding nerds. The audience is UK adults across ages, on Facebook, YouTube and TikTok. The standby symbol and the red standby light are the most universal; the test card is the most UK-specific.
- **(medium)** Party-colour coding — The founders already flagged red/blue as a possible party-colour problem. A mark that is red-on-black only sidesteps blue, but red in the UK reads Labour to some readers; test it against the target reader, who is drifting right.
- **(low)** Evidence is thin on named 'cliche' commentary — Only 8 searches were allowed, and no Brand New or LogoLounge article explicitly ranks braces or brackets. Saturation is shown by stock counts and the 2012 gallery, not by a named trend report.

## Logo ideas this agent proposed

### The Broken Ring (standby eye)

**Sketch in words:** Solid near-black square tile with rounded corners. In the centre a thick ring, about 60% of the tile width, drawn in red (#cc2b37 or similar), open at the top exactly as the standby symbol is. Down through the gap drops a short vertical bar that stops in the middle of the ring, like a pupil or a blade of light. Stroke weight equal on ring and bar. No wordmark on the tile; the wordmark 'BadCode' sits beside it in a heavy lowercase grotesque with a single red letter O echoing the ring.

**Why it fits:** Universally recognised (IEC standby symbol, on every TV in Britain), yet it also reads as an eye with a slit pupil, and it carries the story: the machine is not off, it is on standby across time. It reuses the vertical blade of light from our register. Simple enough to draw in three strokes.

**Weakness:** The power symbol is crowded (Gateway, Staples, Garbage, countless apps) and a bare version reads as a power button. It could be misread as 'sleep' rather than 'threat'; needs the red and the tile to become ours.

### The Stuck Pixel

**Sketch in words:** A pure black square field. A single red SQUARE (not round) sits slightly off-centre, low and to the right, about one-twelfth of the tile width, with a faint 1-pixel red halo in the darker red. Nothing else. For video ident: screen is black, the square is already there; the screen slowly develops the full wordmark around it, or the frame flickers and the square is the only thing that survives.

**Why it fits:** A dead or stuck pixel is a fault in your own screen that you can't fix and can't un-see, so it is the cheapest, most ownerless menace there is. Being square differentiates it from HAL, Leica and every round red dot. Draws in two seconds with a marker: fill a black square, dot one red square.

**Weakness:** By definition tiny, so it fails at 16px and looks like a rendering error or dust on an avatar. Needs a fixed frame (thin red keyline around the black tile) to read as deliberate. Likely to look like nothing to someone who hasn't seen the whole channel.

### The Answer Diamond

**Sketch in words:** A solid black diamond (a square rotated 45 degrees) with sharp corners, filling roughly 80% of the tile, on a white or dark-grey background. Inside, low and centred exactly where a question mark's dot would sit, a small red circle. The question mark's hook is deliberately absent. Only the dot remains. Optional: a very thin vertical white slit above the dot, evoking the missing stem.

**Why it fits:** It is the replacement character, 'we could not decode you', turned round: BadCode is the thing that already decoded us and no longer asks a question. A diamond with a dot also reads as a warning sign or a lozenge, an authority shape. Ownerless.

**Weakness:** Hook removal loses the recognisable question mark, so only nerds will get the reference. Without it, it is a red dot in a black diamond, close to a hazard sign or a slot-machine gem. The replacement character is also a friendly-confused symbol, not a threatening one.

### Tofu Letter

**Sketch in words:** Wordmark 'BadCode' set in a bold, ordinary sans. Every letter is normal except the 'C', which is replaced by the missing-glyph box: a tall thin rectangle outline (about 0.6 of cap height wide, cap height tall), white stroke, with a small solid red rectangle inside its lower half. At avatar size, crop to the box and the red bar alone: a tall outlined rectangle with a red bar.

**Why it fits:** It answers the brief head-on: it keeps the founders' 'C is a symbol' idea but swaps the code punctuation for the empty box every person has seen when a font can't draw a letter. 'Bad code' becomes literally code that couldn't render. It is deadpan and drawable in seconds.

**Weakness:** Still a 'letter replaced by symbol' trick, the same move as the curly-brace C, just in a fresher vocabulary. The tofu box is a well-known typographer joke, and it looks like a missing-font bug on a real page. Weak as a standalone avatar.

### The Frozen Loader

**Sketch in words:** A spinner made of twelve short radial ticks arranged in a circle on black, all in dim grey except one tick, at the 12 o'clock position, drawn a bit longer and in red. The ring is static: the loader has stopped on one tick. In video, the ticks spin then all lock on the red one. Red tick length about 1.5x the others.

**Why it fits:** The loading spinner is the most universal computing image on earth (nobody owns it: Wikipedia notes no major company uses one as a logo) and the 'still loading' feeling is a good metaphor for a machine that has been counting down to the future. The single red tick is a clock hand and a slit-eye at once.

**Weakness:** At small size twelve ticks turn to mush, and a static spinner looks like a sun, a camera shutter or a settings cog. The story is less immediately menacing than the other ideas.

# Social media accounts

Where BadCode lives online: which accounts exist, which are still to open, and the name each one
uses. Update this file the day an account is opened.

**Handle rule:** `badcode` everywhere. If it is taken, pick ONE fallback (`badcodetv` or
`badcode_tv`) and use it identically on every platform ([`plan.md`](./plan.md) §7). Avatar = the
logo in [`docs/brand/logo/`](../brand/logo/).

**In use (2026-10-20): `badcode.tv`** is the handle on Instagram and X, so it is the fallback to
match on every new account where `badcode` is taken.

**Logins:** the badcode email is badcode.tv@gmail.com. YouTube, TikTok, Facebook and SoundCloud sign in with
it directly. All the accounts share one password: **ask Jack**.
Passwords and API keys never go in this repo.

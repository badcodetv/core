# The Forecast

A BadCode short (Jack, 2026-11-21: "lets do this"), from eight shorts built on the BadCode government's policies.

**The idea:** a TV weather presenter (BadCode in the balaclava) forecasts the economy like the weather; the camera pulls
back to a man in a suit off-set, blowing the clouds across the map with a desk fan.

**The point:** money troubles get reported like the weather, as if nobody decided them. Someone did.
**The way out:** every cloud gets a name tag: who decided. The BadCode government's Chancellor policy `the-ledger`
("every pound has an address"; the Chancellor's brief guards against "austerity told as weather").

# rain-and-room-ambient: what shaped it

- **Structure of the style box** follows the ambient formula seen in community guides: subgenre, then texture sources (pads, drones, field recording), then mood, then how it evolves, ending on production words. Kept to a focused set of descriptors because overloading dilutes focus. "Slowly swells" is the evolution cue; no uniformity words. (https://hookgenius.app/learn/suno-ambient-prompts/, https://undetectr.com/blog/suno-prompts-for-ambient)
- **"Instrumental" stated up front, and drums/beat excluded**: guides say Suno adds a beat by default if the slot is left open in ambient. (https://undetectr.com/blog/suno-prompts-for-ambient, https://hookgenius.app/guide/lofi-ambient/)
- **Bans go in Exclude, not as "no ..." in the style box**: Exclude loses force if the positive prompt asks for the same thing indirectly, so the style box never names piano, strings or melody. (https://diyai.io/ai-tools/audio-generation/suno-exclude-styles/, https://jackrighteous.com/en-gb/blogs/guides-using-suno-ai-music-creation/negative-prompting-suno-v5-guide)
- **Rain as named surface** ("tapping a window pane"): rain prompts work better when the surface is concrete. Caveat noted: Suno renders rain as a musical texture rather than true field audio, so a real rain layer may still be wanted in the edit. (https://suno.com/playlist/dd70c6bc-aaa6-41b9-b857-cfe5caa1dd3d, https://morphic.com/id/resources/music/rain-music)
- **Bed under dialogue**: voice body sits around 500-1000 Hz and presence around 2-4 kHz; carve the bed there rather than only ducking. Hence "low-passed", "far back", "hollow midrange", sub pulse below and a bright chime only at the end when nobody is talking. (https://www.dvinfo.net/forum/all-things-audio/174579-audio-eq-settings-voice-music-mix.html, https://morphic.com/resources/how-to/how-to-mix-sound-effects-with-music)
- **Settings**: Variety off so the tags are kept as written; Style Influence 65 to hold the texture brief; Weirdness 40, moderate, since high style plus high weirdness pulls apart. (https://jackrighteous.com/ja/blogs/guides-using-suno-ai-music-creation/how-to-use-suno-s-advanced-sliders-weirdness-style-audio-influence, https://blakecrosley.com/blog/suno-style-field-style-influence)
- **Unverified**: whether v6 will place the click-click-click and chime in the last seconds from a style-box cue alone, with no lyrics to carry section tags. If it lands early or not at all, the ending may need ffmpeg/Premiere SFX instead.

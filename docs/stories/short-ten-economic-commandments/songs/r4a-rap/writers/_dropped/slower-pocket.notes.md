# slower-pocket: notes

The Style box is the kept box with two edits and nothing else changed. It comes to about 936 characters, under the 950 limit.

1. The tempo goes from 88 BPM to 84 BPM. Several guides say Suno treats a BPM as a request, not a hard setting. So the small tempo drop is backed up by pacing words in the prose.
2. "then tumbled out in quick clusters" is now "then each line unspools at an easy conversational walk, one rhyme cluster to a bar, nothing squeezed". Practitioner guides on rushed Suno vocals agree that rushing is mostly a problem of too many syllables per bar. They also say "easy"/"unhurried"-type descriptors in the style prompt slow the delivery, and "fast/driving" words speed it up. The lyrics are locked, so I couldn't cut syllables. Instead the box asks for one cluster per bar.

Lyrics: the locked words, unchanged. Each rule has a section tag ([Rule One] to [Rule Ten]), and there are [Intro]/[Outro] tags around the first line and the fix. Each rule gets its own block so every number can land on its own beat.

Exclude: "double-time, rapid-fire flow" are there to keep the cramming out. Settings: v6, 75 s, male, weirdness 35, style influence 70, variety normal, max mode off.

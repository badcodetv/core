# figure-r6 notes

## Method (from research)
- Give each attached image a job in plain words: "Image 1 is the place", "Image 2 is the man". Google's Nano Banana guide recommends stating what each reference image is for.
- Say outright that the place stays as it is ("keep ... unchanged") and list the main layout anchors, so the model holds the perspective and doesn't invent a new scene.
- The reference sets who the man is. The text adds only what's new: where he stands, how big he is in frame, his gesture, and the light he picks up from the scene.
- Figure reference RU4-3-a also shows two other people. Every prompt says "use only the masked man" so they don't carry over.
- The clothing is named briefly (baggy beige suit, black roll-neck, dark cap). The mandated balaclava sentence covers the mask, and every hand is written as a "glove".

# lullaby-piano-to-silence: notes

What shaped it:

- **Tags over chat, the spine named first.** Guides say Suno reads comma-separated descriptors better than conversational sentences, and gives "felt piano, 65 bpm" as a working example. So the box opens with instrumental / solo felt piano / key / bpm, and the 15 s arc follows as short clauses in time order: one melody, then many copies, then the stop, then one phrase, then the note and the horn.
  https://alexanderweichart.de/2_Areas/Music/Suno-Instructions
- **No negative words in the style box.** Suno has no true negative box beyond Exclude; reinforce the opposite instead ("solo piano, beatless"). The style box says "solo", "instrumental" and names one performer; every banned thing lives only in Exclude. "Lullaby" is a vocal-summoning word (a common lullaby template has "soft female vocal"), so it is fenced by "instrumental" up front plus vocals / singing / humming in Exclude.
  https://jackrighteous.com/en-us/blogs/guides-using-suno-ai-music-creation/suno-4-5-plus-prompts-101-get-the-sound-you-want
  https://howtopromptsuno.com/style-lyrics/how-do-i-make-instrumental
- **The silence is a suggestion, not a timer.** Pause cues shape space but do not hit an exact time; a gap that must land on a frame is an edit. So the box asks for "a sudden dead stop, under a second of complete silence" and the cut can trim or move the gap onto the grab (about 6 s). "Clear final stop" is the guide's hard-ending phrase, used so the last held note does not fade into a long tail past 15 s.
  https://jackrighteous.com/blogs/guides-using-suno-ai-music-creation/master-pauses-silence-in-suno-ai-pause-intro-silence-song-flow
  https://jackrighteous.com/en-gb/blogs/guides-using-suno-ai-music-creation/suno-ai-fade-out-prompt-guide
- **THINK! silence trick: unverified.** I found no source describing a THINK! drink-drive ad that uses a sudden silence; the brief's reference is kept as given, not confirmed. The nearest is the Irish RSA "silence" campaign, which is about friends keeping quiet, not sound design.
  https://www.rsa.ie/road-safety/campaigns/drink-driving

Settings: v6 (fixed), duration 15 (fixed). Weirdness 45 and Variety normal leave room for the tape warp and detuned stacking without wandering off the piano; Style Influence 70 holds the solo-piano spine and the arc. vocalGender null (instrumental). maxMode off.

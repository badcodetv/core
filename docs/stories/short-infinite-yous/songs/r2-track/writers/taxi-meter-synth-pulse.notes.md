# taxi-meter-synth-pulse: what shaped it

- **Instrument names and a number over adjectives.** Practitioner guides say a numeric BPM is obeyed where a described tempo is ignored, and that named instruments leave the model less to guess, so the box names the machines (CR-78, Jupiter-8, Prophet-5, CS-80) and states 120 BPM instead of a genre tag. Sources: https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad , https://roo.beehiiv.com/p/complete-suno-ai-prompt-guide-2026-301-styles-the-exact-formula-and-why-your-outputs-sound-random
- **"Instrumental" stated in the box and "No vocals" at its end**, with an empty lyrics box, because Suno defaults to vocals and guides report the empty lyrics box alone is not reliable. Source: https://alexanderweichart.de/2_Areas/Music/Suno-Instructions
- **Under ~100 words, one register** (cold analogue, no orchestral mixing), because contradictory descriptors make Suno compromise. Source: https://roo.beehiiv.com/p/suno-ai-prompt-guide-2026-copy-paste-templates-the-formula-that-actually-works
- **80s sci-fi palette**: sequenced pulses, gated-reverb electronic drums, Jupiter-8 and Prophet-5 as the decade's defining polysynths; gated reverb as reverb cut by a noise gate (one big tom for the kick into the cab). Sources: https://rolandindonesia.com/synthwave-sci-fi-and-sound-design , https://www.musicradar.com/news/10-synths-that-defined-the-80s , https://www.wikipedia.org/wiki/Gated_snare , https://reverb.com/news/the-synth-sounds-of-phil-collins-in-the-air-tonight
- **Timeline written into the box in seconds** (stop at 13 s, then pad + horn swell + whoosh) to map the beats: meter tick = night out, detuned copies = the many versions, bitcrush snap = squeezed back into one, gated tom = the boot, swell + whoosh = headlights on the logo. Unverified whether v6 honours a seconds marker this precisely; Duration is set to 15.
- **Settings**: v6, variety normal, weirdness 45 (some strangeness for the fracture, not chaos), styleInfluence 70 (keep the named synths), maxMode off.

# Magic Money Tree — the host's monologue (October 2026)

**Status: script skeleton for Jack, 10 October 2026. Not ruled; Kai has not seen it.**
Jack's calls today: call it **Magic Money Tree** for now; **no games**, just the host's monologue;
use **all** the stories on the board; **script before any stills**.
The news board and sources are in [`topical-show-2026-10.md`](./topical-show-2026-10.md).

**How to read this.** Jack writes the jokes. So each beat gives: the fact the host has to get out
(plain, checked), what the beat is for, what there is to joke about, and an empty line for Jack.
The plain fact lines are mine and can be reworded freely.

**One practical limit.** A talking clip is 8 seconds, one speaker. That is about 20 words. So each
line below wants to be one or two short sentences, or it gets split across two clips.

## The thread that holds it together

One phrase comes back all the way through: **"there's no money."** It is said straight in beat 2
(the nurses), and then every later beat is money turning up for someone else. He never explains it.
The last beat gives the phrase back one more time.

## The monologue

Running order, about three and a half minutes. Beats 2 and 3 are the heart; cut from the back if it runs long.

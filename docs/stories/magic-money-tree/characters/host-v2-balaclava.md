# Round 2 — eight designs in a new Flow project (2026-10-25)

**Brief (Jack):** "start a new project in flow, and come up with a bunch of differnet designs for him Please avoid
elements of 'AI slop' (research the internet on how to do that.) Please optimise this prompt for Nano Banana 2/Omni
Flash on Google Flow … Also use the cinematography file and skills in the repo."

## What round 1 got wrong (shot-craft, Diagnose)

All six round-1 stills are **too perfectly arranged**, which is the register the research says people call AI:
dead-centre and symmetrical, hands posed in a clasp, an empty glowing blue screen, a clean set with no wear,
"rim light" from an invisible source, and a generic "shot on 35mm film" capture.

## The rules for this round (research, then the repo's own findings)

Sources: `docs/google-flow/nano-banana-2.md` (anti-slop toolkit, sixth pass), `docs/google-flow/2026-10-08-anti-slop-sweep.md`,
`docs/cinematography/` (gates, frame), plus the web pass below.

- **Describe the capture, not the beauty.** Each prompt names one humble camera and a stock, carried through every
  clause. No Portra 400 or CineStill (over-prompted); Kodak Gold 200, Ektachrome or Ilford HP5 instead.
- **No quality words:** no cinematic, photorealistic, 8K, masterpiece or beautiful.
- **One light source, named and placed in the world**, plus what it causes. No golden hour (it's an AI signature).
- **Off-centre, not quite level, with something in the foreground**, and something the host is *doing* (mid-action).
- **Wear and mess in the set:** dust, tape, a stain, cables.
- **Name exact materials** ("cream merino, slightly pilled") rather than "a mask".
- **No unspecified text:** signage the prompt doesn't define gets invented, so the screens show pictures, not words.
- **Left/right is a stated weak point** (Nano Banana 2.1 model card): place the triangle by landmark ("high on the
  ring, over one eye"), and keep "camera-left" for the light only.
- **Built for Omni later:** the mask is already on, the head is chest-up or closer (small faces are a stated weak
  point), and no mouth is seen. Omni guides: the start frame sets the ceiling; keep the video prompt a short shot
  brief; write "single continuous shot"; describe the audio.
- **Every prompt ends "Thanks."** Nano Banana 2, 16:9, x2, a new project.

Web pass, 2026-10-25 (only what was new): Google's guide (6 Mar 2026) says start with a verb, write narratively, name
hardware ("a cheap disposable camera") and exact materials ("navy blue tweed", not "suit jacket"), and use positive
framing. The Omni Flash 1.1 guide (Morphic, Aug 2026) says to keep the prompt a short brief, add "single continuous
shot, no scene cuts", one change per turn, and that unspecified on-screen text gets invented.
Sources: [Google Cloud — ultimate Nano Banana prompting guide](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-nano-banana) ·
[Morphic — Gemini Omni Flash 1.1 guide](https://morphic.com/resources/how-to/gemini-omni-flash-1-1-guide) ·
[Atlas Cloud — Nano Banana 2 prompts](https://www.atlascloud.ai/blog/nano-banana-2-prompts-guide) ·
[Fliki — Nano Banana 2 playbook](https://fliki.ai/blog/nano-banana-2-prompting-guide).

**The constant in every design:** the logo is the face, as a thin black ring around the face with a small red
triangle with rounded corners high inside it, over one eye. No skin anywhere.

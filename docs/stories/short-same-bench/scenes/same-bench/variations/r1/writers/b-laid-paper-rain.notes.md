# b-laid-paper-rain — notes (redo)

Redo: the sameness gate flagged "for a caption", shared across the round. The headroom sentence is rewritten in this prompt's own words ("the drawing simply stops: bare ribbed sheet ... left empty so words can be set over it afterwards"), and the word "caption" is dropped. Nothing else changed.

What shaped it:
- Laid paper has wide-spaced chain lines with close, fine laid lines crossing them, both left by the wire mould. Drawing media sit more heavily on the raised lines than in the hollows, so the pattern shows through tonal work. That is why the prompt asks for tone from broken, striped grain rather than from wash. Sources: https://en.wikipedia.com/wiki/Laid_paper, https://lob.is.ed.ac.uk/taxonomy/term/96, https://lob.is.ed.ac.uk/taxonomy/term/252
- Ingres-type laid drawing paper has a toothy grain of close lines, which points to a heavy cream sheet. Source: https://Www.wikipedia.org/wiki/Ingres_paper
- Unverified inference: no source covers dip pen on laid paper specifically. The broken, banded hatching is my guess at how the effect reads.
- Rain made from diagonal strokes all slanting one way stands in for the grey tone, so the umbrella stays the only solid black.

# c-banknote-engraving-portrait (r2 redo)

Rewrote to drop the shared "caption to be added later" wording: the blank space is now described as bare upper and lower thirds of the page, with no mention of what it is for.

What shaped it:
- Banknote portraits are built from fine lines, dots and dashes varying in size and shape; burin lines are steady with clean edges -> "steady burin grooves", stipple and dashes fading into bare paper on highlights. https://webarchive.library.unt.edu/eot2008/20090114203445/http:/www.bep.treas.gov/document.cfm/5/44/322 , https://newworldencyclopedia.org/entry/Engraving
- Darkness by dense parallel lines, crossed sets for deeper shadow -> second set crossing in the brim and jaw shadow, near-solid crosshatch for the coat. https://www.wikiwand.com/en/articles/Art_and_engraving_on_United_States_banknotes
- Central elliptical vignette tradition; guilloche is a separate lathe-made background, so it is excluded explicitly to keep the frame plain. https://learn.planetbanknote.com/how-banknotes-are-printed/ , https://coleccionismodemonedas.com/en/guilloche
- Intaglio plates leave plate tone and a pressed dent in the paper. https://cavac.at/cavacopedia/Intaglio%20%28printmaking%29

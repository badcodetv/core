- Period line: newspaper cartoonists of the 1910s mostly drew a looser pen line than the meticulous cross-hatchers (McCay, Nast), so the prompt asks for swift unbroken outline with only a few hatch strokes. https://bergetoons.blogspot.com/2019/06/gladly-crosshatched-bear.html ; https://webarchive.library.unt.edu/eot2008/20090103101440/http:/www.loc.gov/exhibits/cartoonamerica/cartoon-political.html
- Line, not halftone: halftones cost more than line blocks, so cartoonists suggested tone with line; hence flat black shadow puddles and bare paper, no grey wash. Paper grain noted from McCutcheon's 1910s textured stock. https://www.culturalheritage.org/docs/default-source/annualmeeting/2014am_poster04_from_pen_to_press.pdf?sfvrsn=2

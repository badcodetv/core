# c-alone-at-sunset-wide (r2 redo) — notes

Rewritten after the sameness gate flagged shared wording ("a tall silk hat", "frock coat", "for a caption", "clear for a caption added later", "no lettering captions"). The hat is now a "black stovepipe topper", the coat a "morning coat", the empty sky "an open field reserved for overlay text", and the no-text line is a "Negative prompt:" clause instead.

What shaped it:
- Nano Banana 2 has no negative-prompt parameter, but a "Negative prompt:" clause written into the prompt is obeyed, so the no-writing instruction goes there. https://runware.ai/docs/models/google-nano-banana-2/guides/prompting.md
- Without layout instructions Nano Banana centres the subject on an empty background. Here centring is wanted, but the guide's advice to state the position and the reserved sky area explicitly is followed (exact middle; upper half bare). https://www.curify-ai.com/blog/10-prompting-tips-nano-banana
- Ink-wash vocabulary (graded tones, varying ink density, deliberate empty space), and naming where the negative space sits for overlay text. https://carat.im/en/prompt-gallery/ink-wash-painting and https://docs.mew.design/blog/tags/ai-image-prompts
- To stay off any one source panel: our own ground-level vanishing-point composition, the man alone with pigeons and no second figure, our own costume (stovepipe, morning coat, spats). No artist or publication is named.

Settings: Nano Banana 2, 9:16 (fixed by the story).

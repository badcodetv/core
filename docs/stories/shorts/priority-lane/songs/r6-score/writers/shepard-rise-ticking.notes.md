# shepard-rise-ticking — what shaped it

- **The illusion, described by what it does.** Octave-stacked layers where each climbs while a new one fades in below, so the pitch "keeps rising but never arrives". The pairing with a real watch tick as the only metric pulse is documented in coverage of the Dunkirk score (tension with no resolution; the tick was a recording of a real watch, turned into the score's pulse). No composer named in the prompt, as the brief asked.
  - https://www.coffeeordie.com/dunkirk-auditory-easter-eggs
  - https://rosetta.to/u/vox/the-sound-illusion-that-makes-dunkirk-so-intense
  - https://www.sfcv.org/article/inside-the-making-of-dunkirks-landmark-soundtrack
- **Suno v6 Styles box.** Jack Righteous's v6 guide says name a foundation first and treat the rest as accents, a longer prompt is not more control, and unwanted things go in Exclude rather than in Styles. So the prompt opens with the foundation (low strings + synth pad, watch tick) before the time shape, and every ban is in Exclude. The same guide puts structure in the Lyrics box with section tags. This experiment puts the time shape (0 s rise, about 5 s stall on a held unison, just after 10 s hard cut) in plain sentences in Styles, because the lyrics box must stay empty for an instrumental. Untested: we don't know if v6 follows timing written in seconds.

  - https://jackrighteous.com/es-us/blogs/guides-using-suno-ai-music-creation/suno-v6-ignoring-prompt-how-to-diagnose
- **Room for voices.** "Sitting low" and no melody are there so the shouted dialogue sits on top. Drums, kick and snare are banned so the tick stays the only rhythm. Fade-out is banned so the music cuts dead. The stall is placed at about 5 s, where the picture holds at the red light. The track is 20 s, so the edit can find the real cut point near 10.5 s.
- **Settings.** v6 rather than Wild, because the shape matters more than surprise. Style influence 75 to hold the instrumentation. Weirdness 35 keeps it unpolished but not chaotic. Variety normal. No vocal gender.

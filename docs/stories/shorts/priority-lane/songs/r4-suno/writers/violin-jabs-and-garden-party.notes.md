# violin-jabs-and-garden-party — notes (redo)

Rewritten after the sameness gate flagged shared wording ("monitor tone then", "dialogue not singing", "not singing english", "spoken dialogue not"). All delivery and ending phrasing is new: "talked and yelled rather than sung", "one unbroken ECG beep, nothing after", "ECG pips".

What shaped it:
- Third-party v6 guides say spoken delivery is a tendency, not a guaranteed mode, and that accent is set through voice descriptors and style tags with no promised dialect fidelity, so if the accent comes out faint the advice is to make the delivery description stronger. That is why each line has a per-line tag (who speaks, which region, how) and the style box names concrete accent markers (Somerset burr, flat Bolton vowels, Home Counties for the minister) instead of just saying "British". https://sunowatermark.com/blog/suno-v6-vocal-prompts-2026/ , https://jackrighteous.com/es/blogs/guides-using-suno-ai-music-creation/suno-ai-spoken-narration-workflow
- The same v6 guide lists Max Mode for vocal consistency on voice-led tracks, so maxMode is on. (Unverified for speech; worth A/B.)
- Minuet: moderate triple time with short, regular phrases. That is why "triple time" and "prim" are in the box, so the garden-party music reads as a dance and not as underscore. https://books.openbookpublishers.com/10.11647/obp.0314/ch3.xhtml
- Accents: West Country speech is traditionally rhotic (the "burr"), Lancashire has many town-by-town varieties (Bolton was picked as one concrete town), and Cumbrian has Northumbrian/Norse roots. https://en.wikipedia.org/wiki/Regional_accents_of_English , https://en.wikipedia.org/wiki/English_language_in_Northern_England
- "hard gap of silence after it" sets the violin jab up as punctuation (Kai's scream → jab → quiet pattern), so the jab doesn't become a running ostinato.

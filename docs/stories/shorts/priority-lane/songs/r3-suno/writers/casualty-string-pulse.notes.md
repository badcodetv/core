# casualty-string-pulse: what shaped it

- **Speech through the song model.** Guides say to describe a voice-forward, low-dynamics bed, strip anything about hooks or choruses, and put the "not sung" negatives in words. Short, punctuated lines plus a delivery cue above each line steer delivery better than adjectives in the style box do. Hence one bracketed speaker-and-delivery cue per line, and "no singing" in the style box. Sources: https://jackrighteous.com/blogs/guides-using-suno-ai-music-creation/suno-ai-spoken-narration-workflow , https://sunowatermark.com/blog/suno-v6-vocal-prompts-2026/
- **Suno Speech beta.** Reported launched 2026-10-01 (unverified, third-party). It is separate from Custom Mode, and the source says it is not word-for-word. This prompt targets the v6 song model so the score and the voices come back in one take.
- **Three voices.** No official dialogue syntax exists. The community method is a per-line speaker tag plus a note about the voices in the style box, and it is called a steering cue, not a guarantee. So each voice is described once in the style box (age, register, timbre) and tagged again by role on every line. vocalGender is left null because the cast is mixed. Sources: https://jackrighteous.com/blogs/guides-using-suno-ai-music-creation/duet-harmony-theme-meta-tags-suno , https://libreddit.winscloud.net/r/SunoAI/comments/1ji0g3c/guide_how_to_make_good_songs_with_multiple_voices
- **The score.** Casualty's theme is Ken Freeman's synth piece, and recent seasons are scored by Justine Barker. I found no source for the show's instrumentation, so the "spiccato low strings" bed is the brief's idea rather than a researched fact. The style box asks for a genre and an instrument list only, never a melody. Sources: https://filmmusicreporter.com/2023/01/09/soundtrack-album-for-bbcs-casualty-released/ , https://watch.plex.tv/person/ken-freeman-11
- **Settings.** Core v6 is recommended over Wild when consistency matters, and Max Mode is aimed at vocal consistency (third-party sources). Weirdness is moderate, so the hard stop and the siren can land without the take drifting into a song. Duration is 14 s, because a set duration is obeyed.
- **Structure.** The bracketed directions carry the edit: the strings race, stop dead at the red light (leaving clock and rain), then the tone, then silence with no music over the flatline. The excludes ban cheerful, major key, choir and reverb tail so the end stays dry and empty.

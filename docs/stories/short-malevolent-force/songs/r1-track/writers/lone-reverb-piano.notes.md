# lone-reverb-piano: notes

What shaped it (web research, 2026-11-16):

- The YouTube page (https://www.youtube.com/watch?v=LGD79pQY1kI) only exposes the title "Damned"; no description was readable.
- Hooktheory's TheoryTab of the track (https://www.hooktheory.com/theorytab/view/kevin-sherwood/damned): E minor, 180 BPM, 4/4, i-VI (Em-C) core with iv and v; melody B4-D6, mostly stepwise, half-beat notes. Basis for "E minor at 180 BPM", "up high", "stepwise", "running eighth-note figure". User-submitted transcription, so an estimate.
- Wiki/review summaries surfaced by search (https://breezewiki.discard.no/callofduty/wiki/Damned, https://www.sputnikmusic.com/album/70867/Treyarch-Sound-Call-of-Duty-Black-Ops---Zombies-Soundtrack/; both blocked a direct fetch, so the search summary is all I had): piano-driven, "echoey, creepy piano notes and simple melody lines" with "menacing background growls and clicks". Basis for the cavernous reverb, the growls and the clicks, and for leaving out drums.
- VGMdb (https://vgmdb.net/album/29513) credits a keyboard performer: it is piano-led.
- Nobody listened to the reference itself; everything above is secondhand.

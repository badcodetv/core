# neurofunk-reese-machine: notes

**What it's for:** a hard, instrumental neurofunk loop to cut in after the hymn. It has to land at full weight on beat one, with no build, while the gang tears up THE RULES.

**What shaped it:**
- **The genre tags.** The style box names the subgenre outright (neurofunk, techstep) and adds "mechanical / technical / dark" descriptors, not just "drum and bass". Guides say Suno follows named subgenres more closely: https://hookgenius.app/learn/suno-dnb-prompts/ , https://usesuno.pages.dev/guide/genre/electronic-edm/drum-and-bass
- **"Breakbeat" / "two-step".** These are written in so the drums don't fall back to four-on-the-floor, and four-on-the-floor is also excluded. Community tips: https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad
- **The Reese.** "Phase-beating detuned saws" is used because the beating between detuned saws is what makes it a Reese. "Mutates every bar" borrows the neurofunk habit of call-and-response bass edits: https://blog.landr.com/reese-bass , https://www.loopmasters.com/articles/4270-How-To-Make-a-Neurofunk-Drum-and-Bass-Drop-in-Ableton-Live
- **Neurofunk versus techstep.** Neurofunk is the cleaner, more clinical descendant of techstep's distorted Reese (No U Turn, Ed Rush & Optical, then Noisia and Teebee). Both tags are used to get the clinical polish with some techstep grit: https://en.wikipedia.org/wiki/Techstep , https://bassgorilla.com/what-is-neurofunk/
- **The excludes.** These block every voice route (vocals, chops, MC, rap, choir, humming), the build and breakdown routes (intro, riser, breakdown, ambient), and the neighbouring lanes the other writers own (amen jungle, wobble, liquid).
- **The lyrics box.** Only bracketed section directions after [Instrumental]: one long Drop with no breakdown, so the take is a single loopable block. One guide suggests structure tags in the lyrics box for instrumentals.

**Settings:**
- v6, not Wild: a clean genre read is wanted.
- Weirdness 35, so the bass can mutate without the genre drifting.
- Style influence 80, so the tag box dominates.
- 45 s gives the editor several loop points.
- Variety normal, no vocal gender, Max mode off.

**Caveat:** most of the Suno-specific advice comes from unofficial guide sites, so it is a starting point, not tested behaviour.

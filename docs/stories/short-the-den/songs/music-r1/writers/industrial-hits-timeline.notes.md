# industrial-hits-timeline: notes

- The timeline is written in the style box with timestamps, as the brief asks. Section-by-section mapping, saying what each part does, and naming the transitions is the advice in the v6 arrangement article (https://sunowatermark.com/blog/suno-v6-instrument-prompts-2026/). The same advice says sections should state only what changes (https://github.com/mttkllr/suno-field-guide).
- Kept under about 100 words, because community roundups report that longer style prompts get treated as optional (https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad). The instruments are named as concrete objects (taiko, sheet metal, anvil) rather than adjectives.
- Sound palette: stock cinematic-percussion listings pair taiko with industrial clangs, metallic risers and low drones for tension (https://www.tunepocket.com/royalty-free-music/cinematic-strikes/, https://www.ujam.com/tutorials/epic-drums-for-video-game-and-film-soundtracks/).
- Speech room: "no melody, mid-range left open for dialogue" and "wide gaps between hits" so the nine voice lines sit on top. "melodic lead" is in the exclude box for the same reason.
- At 110 BPM one bar lasts about 2.2 s, so the riser gets about one bar (0:30-0:32) before the 0:32 impact. The 0:33-0:43 tail covers the end card and the rainy-window logo.
- Settings: v6 (not wild) with moderate weirdness 30 and styleInfluence 75 to hold the timeline. durationSec is 43 for the 42.8 s cut. maxMode is off because the texture is sparse.

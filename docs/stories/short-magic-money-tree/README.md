## The idea (slate #36, picked by Jack 2026-11-11)

A minister shakes a tree labelled HOSPITALS: nothing falls. "We can't afford it." (5) → he shakes the tree next to it,
labelled BANKS: money pours (4) → he looks at camera: "Different tree." (2). **11s.** Draft words `by: claude`; Jack writes the final jokes.

**Point:** "we can't afford it" is a choice about who gets the money, not a fact about whether it exists.

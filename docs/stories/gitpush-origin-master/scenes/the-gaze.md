# The gaze — the machine measures the world falling

> **Kai, 2026-09-17:** the scenes lean too hard on passive environments and a slow camera. Make it
> Armageddon / Day After Tomorrow scale. The machine moves into the data centres, sends its
> attention out, and measures the human signal failing — each metric as a vast real scene with the
> machine's overlay on top — then cuts fast into the three bulletins, ending in Swindon.
>
> **Round 1 ask:** *"a large number of options for each of these scenes so we can hone in."*

**What this file is.** The option-still round: 14 shots × 5 deliberately different framings × 2
candidates. No ruling has been made on the overlay look, the Swindon payoff or the four images —
these stills exist so those rulings can be made by looking. Every overlay, word and number is a
post job; no prompt asks for text.

Where it plugs in (per the Fable pass): the grid opener sits before `plant-room-recut` B1; shots
02–11 sit between B5 (the four gauges) and B6 (the red alert); 12–14 are new beats for the three
bulletins.

Settings: Nano Banana Pro · 16:9 · 2 outputs · `flow_generate_batch` one call per shot, `resume: true`.

**Shared tail**, appended to every prompt:

```tail
Hyper-realistic documentary photograph, fine 35mm film grain, no text, no lettering, no signage, no logos, full-bleed frame with no borders and no letterbox bars.
```

House rules applied: no *news / reporter / war / drone swarm / weapon* words; crowds written as
adults; no real brands or named landmarks; no legible screens; destitution not stacked.

# Banks — three arrivals through the network

[Pack index and finishing instructions](./downfall-flow-prompts.md).

**Play order:** N1 → N2 → N3 → SG; repeat the route into NY, then LN. Allow about one second
for each network insert and three seconds for each exterior. These are separate clips joined
in the edit. Three cities represent the reach of the six-bank story.

N3 is the hardware anchor. **Network variation:** A = near-black service lighting; B = visible
material colour; C = amber practical light; D = clinical inspection light. The geometry remains
a traversable path, not a neon data tunnel. Choose one material/light family for N1–N3.

**Exterior variation:** A = close street/plaza at restrained dusk; B = fuller local colour;
C = architecture seen through the closed threshold; D = wet evening/night. Choose actual
facades that remain legible enough for the controlled takeover signature. Bank names and logos
are not needed. City names, if the chosen architecture needs help, can be added in the edit.

Each block is complete. No shared style prefix needs to be pasted.

## Assembly and reference notes

The control-core-to-exterior cut is the acquisition. Place the core's indicator strip and each
facade's affected region in a similar part of the frame, so the eye can carry across the cut.
The repeated controlled light band and the bulletin supply the connection; do not ask Flow to
infer the abstract instruction “the bank is now controlled by AI.”

For each facade, save the selected source before adding any effect. Generate the subtle people
and street movement with the window state held, then composite the signature through a mask of
the actual windows. Restore structure from the accepted source where needed. After the pass,
the selected windows retain their new state; repeated random flickering would lose the arrival.

No existing building photograph is secretly assumed to be attached. These are self-contained
architectural briefs. If a precise real tower is selected at the board stage, use one verified
location image as its architectural reference and label that role explicitly. Maintain real
geographic relationships; do not combine Singapore landmarks into a fabricated skyline just to
make it recognisable. The existing planning note records the architectural references considered.

No one-second generation setting is implied. Take clean short travel intervals from the source
clips. Reuse or re-cut those accepted intervals for the three cities; making three unrelated
network worlds would weaken the repeated action and add avoidable work.

## In one paragraph

**Britain is an old computer that has clicked "remind me later" since 1872.** Every slide is a
desktop with system windows on it: error boxes whose buttons are both bad, installers stuck at 3%,
release notes, bug tickets, notification stacks, an image viewer for the pictures, and a blue crash
screen for the big turn. The taskbar clock reads 1872. Kai: it "fits perfectly with the general
reference of Future Proof: software engineering principles applied to politics."

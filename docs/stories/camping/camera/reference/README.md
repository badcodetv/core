# 2008 skyline reference — shot 1a

Shot 1a is the 2008 City-of-London skyline plate, and
[`../camping-1a-parliament-hill.kml`](../camping-1a-parliament-hill.kml) fixes
the camera on Parliament Hill. Google Earth's historical slider can't serve this

## The census (read off these photographs)

**Standing in 2008:** Tower 42 / the old NatWest Tower — the dark slab, and 1a's
hero — plus 30 St Mary Axe (the Gherkin), Broadgate Tower (still in scaffold and
cranes in the August frame), CityPoint, St Paul's dome, the BT Tower to the west,
One Canada Square at Canary Wharf to the east.

**Not built yet — must not appear:** the Shard, Heron Tower, the Walkie-Talkie,
the Cheesegrater, the Scalpel, 100 Bishopsgate, 22 Bishopsgate, 8 Bishopsgate,
1 Undershaft, and the newer Canary Wharf towers.

**The thing to prompt for is not a building list — it's the density.** In 2008
the cluster is two towers and a lot of empty sky. Today it's a solid wall. Get
the sparseness and the NatWest Tower does the rest.

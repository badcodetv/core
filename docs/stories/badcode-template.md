# Template and rules: a story's `badcode.md`

> The one file read before any work on a story (2026-11-17 context reset, [`../context.md`](../context.md)).

## Rules
- CURRENT ONLY. Present tense. No history, no "superseded", no strikethrough, no "used to", no dates of changes except one "Last ruled:" line per part.
- Never name another story, and never compare to one ("like GPOM's").
- Short: aim 25-60 lines. Quote a working preamble/prompt shape verbatim only if the story has a LOCKED one that is in current use.
- If something is undecided or empty, write "Not decided — run story-style" (look/sound) rather than inventing.
- Library pieces: list each one taken in from `docs/library/` and copy (adapt) its useful parts into Look / Sound / rules. A piece not listed does not apply.
- If the story has several parts with different looks or sounds (e.g. a film and a music video), give each part its own section and say "don't carry one part's look into another".
- Never invent facts. Everything must come from the story's own folder. If two files disagree, the newer dated ruling wins; if you can't tell, say "Unclear: X or Y" in the file.
- Keep links relative and only to files that exist.

## Template
```markdown
# <Story title>

> Read this first for any work on this story. It is everything that applies to it. Nothing from another
> story, from memory, or from a shared doc's examples applies unless it is written here.
> Library pieces this story uses are listed below; nothing else from `docs/library/` applies.

## What it is
<2-4 lines: the premise, the one point it argues, the form (film / music video / short / comic), length if known.>

## Parts
<one line per part: name — folder — state. Omit section if single part.>

## Look
<current look in 4-12 lines: what the picture is, how to ask the engine (the prompt shape if locked), reference images / Flow Characters by name or id, status: LOCKED / EXPLORING / Not decided.>
Flow project: <id, or "none yet">. One project per story; never shared.

## Sound
<music: genre/feel/how to ask Suno, settings if locked. Voices: who speaks, which AI Studio voice/profile if picked. Status.>

## Story-only rules
<rules learned in this story that apply only to it (bullets, max ~8). Omit if none.>

## Library pieces in use
- none yet

## Where the detail is
<links: look.md (full record and history), sound.md, script, scenes, timeline page link if any.>
```

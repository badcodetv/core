# analog-arpeggio-score: what shaped it

- Palette: the gear lists and interviews for the best-known 2010s retro synth TV score name a Prophet-5/6, ARP and Oberheim two-voice synths, a Roland string/organ machine and tape. So the prompt asks for a "Prophet-style polysynth", a sawtooth mono bass, a chorused string-machine pad and "tape warmth" without naming the show or the composers.
  - https://www.synthhistory.com/post/interview-with-kyle-dixon-michael-stein
  - https://www.soundonsound.com/techniques/scoring-stranger-things
  - https://equipboard.com/pros/survive
- Arrangement: a patch breakdown of that score's style calls for a sparse mix with each part in its own register, dark reverb and delay sends, and a filter that opens slowly over the whole piece to build. That gave "cutoff creeping open bar by bar", "dark reverb" and "clean separated mix", and the gap at the midpoint for the spoken line.
  - https://reverbmachine.com/blog/stranger-synths-biking-to-school
- Suno practice: community guides advise keeping the style box under about 100 words, naming instruments precisely, using era-specific cues like "gated reverb" and analog synth names, and stating "instrumental" outright. The style box reads as a short brief that runs in order (intro, kick, drop, return, resolve). A fixed key (A minor to A major) makes the win clear.
  - https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad
  - https://hookgenius.app/learn/suno-synthwave-prompts/
  - https://suno.com/music-library/genres/synthwave
- Settings: v6 (not wild) with styleInfluence 80 and weirdness 30, so the timed structure is followed closely. durationSec 24 gives some room beyond the 15-20 s cut. The exclude box also removes piano, live drums and orchestra so the track stays all synth.

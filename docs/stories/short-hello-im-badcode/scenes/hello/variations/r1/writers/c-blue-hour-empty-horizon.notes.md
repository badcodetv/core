# c-blue-hour-empty-horizon — notes (redo)

Rewritten to drop the two phrases the sameness gate flagged ("of the frame", "or lettering anywhere in the image"); the no-text instruction is now worded differently ("Keep it wordless, with no writing, symbols or printed marks on anything").

What shaped it:
- Blue hour light is soft because the sun is below the horizon, which keeps long-exposure contrast gentle; so the prompt asks for low contrast and clean shadows. https://www.alanranger.com/blog-on-photography/long-exposure-seascapes-guide
- Exposures of 30 s or more turn a choppy sea into a smooth, milky surface; a multi-minute exposure is named so the water reads as one pane. https://iso.500px.com/long-exposure-seascape-tips/ and https://petapixel.com/2023/08/13/minimalist-photography-using-long-exposures/
- Shooting at high tide removes foreground clutter for clean minimalist compositions; added "at high tide so no rocks or sand intrude". https://www.alanranger.com/blog-on-photography/long-exposure-seascapes-guide
- Minimalist seascapes reward breaking the thirds rule; the horizon sits at the bottom fifth, leaving the upper and central areas empty for the logo. https://focus.picfair.com/articles/how-to-shoot-minimalist-seascapes
- Clouds streak in long exposures, which would add movement; the brief wants calm, so the sky is explicitly cloudless.

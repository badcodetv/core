I built the prompt from scratch using only web research. I didn't reuse any old prompts or the Suno skills/repo.

**What shaped it**
- **G-funk basics:** G-funk is slow, hypnotic funk at about 80–100 BPM. It has deep bass, a loud snare and a high, gliding synth lead. The rapping is a slurred, "lazy drawl" that cares more about rhythm and clarity than clever wordplay. That's where the 92 BPM, the violin standing in for the gliding synth lead and the relaxed voice come from ([Wikipedia: G-funk](https://en.wikipedia.org/wiki/G-funk)). One catch: the sources link Moog bass more to Bay Area "Mobb music" than to G-funk itself. I kept "rubbery Moog bass" anyway because the experiment asks for it, and it covers the psychedelic-funk side.
- **The Exclude field:** Things you don't want go in Exclude, not in the style box. Writing "no X" in the style box can actually pull X into the song. A strong positive description of the voice helps keep operatic singing out ([HookGenius](https://hookgenius.app/learn/suno-negative-prompting/), [Songsmith](https://songsmith.studio/blog/suno-negative-prompts-guide)). One guide suggests only 2–3 excluded items, but I kept all five you asked for: opera vocals, soprano, choir, screaming and fast rap. Exclude is a nudge, not a guarantee, so the laid-back voice is also described in the style itself and in every section tag.
- **Settings:** In v6, the Variety slider can rewrite your style text on each take, so I set it to **off** to keep the tags as written. Suno's FAQ says turning it off gives you "full control." v6 also follows delivery notes written inside section tags, so every verse repeats the relaxed, behind-the-beat direction ([HookGenius v6 guide](https://hookgenius.app/learn/suno-v6-guide/)). Example prompts in another guide used Style Influence around 75% and Weirdness around 20% ([roo.beehiiv](https://roo.beehiiv.com/p/best-suno-prompts-v6), [moelueker](https://moelueker.com/blog/suno-v6-guide)). I set Weirdness higher, at 32, to leave room for the classical and psychedelic mix.
- **Tag order:** The style follows genre → rhythm → instruments → voice → mood → texture. I packed the instruments into three combined tags so the voice still starts in the first third. The overture tag mentions only horns and timpani. Every lyric word, spelling and line is unchanged, including the curly apostrophe in "heaven’s".

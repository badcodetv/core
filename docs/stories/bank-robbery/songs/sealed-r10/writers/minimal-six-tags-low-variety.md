I've written one prompt for this experiment. The research gave me three things that shaped it:

- **Variety is the setting being tested.** Suno's own V6 FAQ, as quoted by third-party guides, says Variety rewrites your style prompt and that setting it to 0 keeps your tags as written. So I set Variety to "off", which should keep the six tags intact and make the test fair. That page also warns that Weirdness below about 50 tends to sound flat, so I set it a little under the middle, at 45. ([sunowatermark](https://sunowatermark.com/blog/suno-v6-variety-style-influence-weirdness/), [Jack Righteous slider guide](https://jackrighteous.com/ja/blogs/guides-using-suno-ai-music-creation/creative-control-sliders-suno-v5))
- **Six tags in a set order, with a strong Style Influence.** Blake Crosley's testing suggests four to seven descriptors. He orders them genre, tempo, instruments, voice, production, mood. A precise style box works best with Style Influence turned up, so I used 75. He also says a BPM number is only a rough guide, so I paired "88 BPM" with "slow strut". Things you don't want go in the Exclude box, not as "no ..." in the style box. Commas split tags, so I wrote each tag without commas to keep the count at exactly six. ([blakecrosley.com](https://blakecrosley.com/blog/suno-style-field-style-influence))
- **Changing one thing at a time.** Max Mode is off so nothing besides the style box changes the result. The lyrics have only plain section tags. The tempo is slow, and the duration is set near the 300-second limit, so all 64 lines should fit without pushing the rap faster.

The voice is a deep, unbothered baritone with lots of space. The orchestral stuff (timpani, brass, strings) is merged with the funk (wah guitar, Moog bass, phaser) in the first tag rather than one following the other. Operatic singing, choir, screaming and fast or double-time rap are all excluded. The lyrics are word-for-word, including the spellings "quantative", "dispraxic" and "heaven’s" with its curly apostrophe.

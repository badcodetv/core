I built this one around the libretto idea. The "opera" lives only in the bracket tags: an Overture, two Acts, an Intermezzo and a Finale. The style box describes nothing operatic, and Exclude blocks operatic vocals and choir.

- **Short style box (about 6 descriptors).** One guide found that 4–7 descriptors work best. Past that they compete with each other, and an artist name or an "unwanted" word in the style box is unreliable. So the style box only says what we want, and everything we don't want goes in Exclude. 90 BPM is a rough guide to Suno, not a locked tempo, so "laid-back" and "smooth drawl" set the pace as well. ([blakecrosley.com](https://blakecrosley.com/fr/blog/suno-style-field-style-influence), [jackrighteous negative prompting](https://jackrighteous.com/en-gb/blogs/guides-using-suno-ai-music-creation/negative-prompting-suno-v5-guide))
- **Short square-bracket cues on their own lines.** Each cue changes one thing (energy, instruments or who's in front), and the song ends with [Outro] → [End]. Square brackets are for arrangement and parentheses are for performance. Jack's lyrics can't gain any words, so I put no ad-lib words in parentheses. The "sly, quiet ad-libs" are described inside the brackets instead. Every cue is different, so no act repeats another's instructions. ([jackrighteous meta tags](https://jackrighteous.com/en-gb/pages/suno-ai-meta-tags-guide), [Suno-Instructions](https://alexanderweichart.de/2_Areas/Music/Suno-Instructions))
- **Settings.** Suno's v6 FAQ, as quoted by third-party guides, says Variety rewrites your style prompt and setting it to zero keeps your tags as written. With a style box this short, I set Variety to "off". Style Influence is fairly high (72) because the style box is short and exact. Weirdness is near the middle (45) so the mix of classical and psych-funk can still surprise. I picked plain v6 over v6-wild because it gives more control. ([sunowatermark](https://sunowatermark.com/blog/suno-v6-variety-style-influence-weirdness/), [popularaitools](https://popularaitools.ai/blog/suno-v6-variety-style-influence-weirdness-2026), [datanorth](https://datanorth.ai/news/suno-launches-v6-v6-wild-and-v6-mini), [jackrighteous v6 style](https://jackrighteous.com/blogs/guides-using-suno-ai-music-creation/optimize-suno-v6-style-of-music-prompt))
- **Length.** The lyrics are long, so I set it to 290 seconds to fit every line at a relaxed pace.

I built this from community guides. I didn't find any official Suno documentation, so these points are other users' advice, not confirmed rules:

- **Order and length of the style text.** Guides say to put the genre first and the vocal and production details last, because Suno reportedly gives earlier words more weight. One recommends 4–7 descriptors, since more than that "fight each other into mud." So the style opens with *psychedelic funk*, then *string quartet*, and stays with those two genres. [roo.beehiiv](https://roo.beehiiv.com/p/suno-prompting), [Medium r/SunoAI roundup](https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad), [Blake Crosley](https://blakecrosley.com/blog/suno-style-field-style-influence)
- **Exclude.** Unwanted things go in the Exclude box, not as "no X" in the style text. The positive style text also shouldn't accidentally ask for what you're removing. That's why the style never says "orchestral" or "operatic," only "string quartet." [Jack Righteous negative prompting](https://jackrighteous.com/de-gb/blogs/guides-using-suno-ai-music-creation/negative-prompting-suno-v5-guide)
- **Bracket cues.** Keep them short so they don't get sung, and put each one right before the moment it should affect. A plain [Bridge] reportedly often turns into another verse, so I paired it with a short "quartet only" cue. A separate cue brings the full band back before the last line. [Jack Righteous meta tags](https://jackrighteous.com/de-us/blogs/guides-using-suno-ai-music-creation/suno-ai-4-5-metatag-tutorial), [Meta tags guide](https://jackrighteous.com/de-gb/pages/suno-ai-meta-tags-guide)
- **Sliders.** I set Style Influence high (78) because the style text is detailed. Weirdness sits just under the middle (42) so the two genres blend without the arrangement drifting. Variety is "normal" because one guide says lower Variety keeps the style tags tighter, and this take still needs some room to sound loose. I picked plain v6 over v6-wild for control.

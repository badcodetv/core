**What shaped it**
- **Space bass:** Bootsy Collins's "Space Bass" sound came from the Mu-Tron III envelope filter. Guitar Player describes it as a "watery, wah-wah like effect" that follows how hard the note is played. So I wrote "envelope-filtered space bass, watery and quacking" and put it in the intro with the dry drum break, which pushes the start away from the old Indian opening. Sources: [Vintage Guitar](https://www.vintageguitar.com/18626/mike-beigel/), [Guitar Player](https://www.guitarplayer.com/gear/favored-by-frank-zappa-and-jerry-garcia-the-musitronics-mu-tron-iii-combined-wild-sonics-and-creative-usability), [Guitar World](https://guitarworld.com/features/bootsy-collins-on-parliaments-pfunk).
- **Voice first:** The prompt guides say to put the genre and the voice description near the start of the Style box, because voice details at the end of a long box can get ignored. They also say to repeat delivery cues in short lyric tags. So the geezer description comes straight after "English psych folk funk, 100 BPM", and each section tag is short. Sources: [roo.beehiiv v5.5 guide](https://roo.beehiiv.com/p/suno-ai-prompts-that-actually-work-in-v5-5-2026), [learnprompting](https://learnprompting.org/blog/guide-suno), [Weichart](https://alexanderweichart.de/2_Areas/Music/Suno-Instructions).

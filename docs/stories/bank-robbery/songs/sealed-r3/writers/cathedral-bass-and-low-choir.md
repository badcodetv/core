I wrote this prompt from scratch, using only the brief, my own fetch of the Best one page and a few web searches. I haven't reused any wording from the listening pass or from earlier prompts.

**What shaped it**
- **The Best one page:** its public page only shows the tags "psych folk, funk", and the music doesn't sound like that. So the single music line names only what you can hear: an acoustic guitar riff, stomping drums and about 90 BPM. It doesn't use Best one's text. [suno.com/song/024b82e8…](https://suno.com/song/024b82e8-378c-47bd-bf73-bb5eafea2ed5)
- **The type of performer:** a lay clerk is a paid adult singer in an English cathedral choir. Most come from choral training rather than opera. So I describe the voice by that job (trained, steady, clear words, used to singing in a big stone room) instead of using words like "operatic" or "basso profundo", which would push it towards opera. [Wikipedia: Lay clerk](https://en.wikipedia.org/wiki/Lay_clerk), [Worcester Cathedral bass lay clerk pack](https://www.worcestercathedral.org.uk/media/4dzni2jy/principal-bass-lay-clerk-recruitment-pack-may-2024.pdf), [Southwell Minster](https://www.southwellminster.org/?p=4398)
- **Controlling the choir:** guides say Suno adds group voices whenever the prompt suggests choir lift or call-and-response, and the Exclude box can't stop it. So the Style box names one lead singer first, describes the answering group as a separate thing, and the lyrics place the answers with tags. [jackrighteous guide (June 2026)](https://jackrighteous.com/en-gb/blogs/guides-using-suno-ai-music-creation/stop-suno-adding-crowd-vocals-choirs-backing-voices) (only the search summary; the page itself returned an error), [Medium round-up of Reddit tips](https://medium.com/@aitooldiscovery/suno-reddit-tips-and-prompts-what-r-sunoai-users-actually-do-65b59d51bcad), [roo beehiiv v5.5 guide](https://roo.beehiiv.com/p/suno-v5-5-changed-the-prompting-rules-here-are-the-formulas-that-actually-work)
- **Choir only on the hooks:** the choir answers only in the "Robbery" choruses. The first pair is strict call and response; in the second pair of each chorus block the lead only opens and the choir takes the rest. The verses stay with the solo voice so he never ends up singing in unison with the group. Kai's words are unchanged, and I only added tags in square brackets.
- **Settings:** Variety is off so Suno doesn't rewrite the Style box. I chose model v6, the only setting your brief left open. Everything else is as you set it.
- **One risk:** 428 words in about 200 seconds is tight. Suno may rush the verses or cut the last ones. If it does, try about 260 seconds rather than speeding up the delivery, which you've ruled out.

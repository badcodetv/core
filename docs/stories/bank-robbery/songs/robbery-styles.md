# The Bank Robbery — eight-style sweep

Asked for by Kai, 20 October 2026: try all eight styles, and re-tag the lyrics for each one so the
brackets direct the delivery in that genre's own way.

**Source words:** the `## Lyrics` block at the bottom of [`score.md`](./score.md) (verse 1, chorus,
verse 2), as it stood at commit `9b7f620`. `score.md` stays the master; the words are not
changed here, apart from these spellings, fixed so Suno sings them right:

- `occuring` → `occurring`
- `Hewlitt` → `Hewlett`
- `very welled planned-ahh` → `very well planned-ahh`
- `burring` is **kept as written**, because it may be meant as it is (the printer's burr). If
  "whirring" was meant, change it in `score.md` and here.

**How this sweep is built (the "bold, not meek" rule).** Each style is a complete set of
three boxes (Style, Exclude, Lyrics) and shares only the words with the others. The Style box,
the production sound, the vocal delivery and the bracket cues all belong to the genre. Each Exclude
list bans the other styles' sounds. Every style keeps the song played straight: the jokes are in
the words, never in the music.

**Lyric layout shared by all eight:** a short intro, verse 1, the chorus split into a chanted hook
(the four "Robbery" lines) and a second half ("stacks of ecstatic cash"), verse 2, the hook again,
and an outro. The cue header on each section is at most three directions, because heavier tagging
broke Camping into double time.

**Variety is Off on purpose.** Above Off, Suno rewrites the Style box differently for every take
(proven 2026-09-13). With eight genres under test, each one has to be heard as written.

I wrote one prompt for this experiment, below.

**What shaped it**
- **The reference.** I read both public pages. Both show v6, the title and "psych, folk, funk" tags. In both listening passes the strongest moment was the first "Robbery, robbery" hook, so the hooks get the biggest lift. The 3:45 ride-out was the weakest point and the takes ran about 4:28. So I set 255 s, put a hard `[End]` after the last hook and wrote a short outro tag. The second take was heard as "UK rap / boom-bap". To keep him away from that, the style box and the verse tags say he talks and half-sings and never raps.
- **Dry room.** A guide on Suno's Exclude box says it steers the result but doesn't mute anything, so I didn't rely on it alone. Every dub, spring and delay instruction from the old prompt is gone from the style box and the tags. I also wrote "no reverb, no echo" into the style box, which a tips source says works more reliably on recent versions. The sources say vocal descriptions buried at the end of a long style box get ignored, so the voice comes second, near the top. The "close-mic, dry" wording is repeated in the section tags, as the same source suggests.
- **Western and opera.** These follow the Leone/Morricone sound. The whistler was Alessandro Alessandroni, with a pure, flute-like whistle over a twangy guitar. The soprano was Edda Dell'Orso, whose wordless voice was used as an instrument. I left their names out of the prompt. The soprano is tagged in the hook sections only.
- **Exclude box.** It keeps the full reference list and adds reverb, echo, delay, dub and hall. Excluding "hall" might thin out the soprano a bit, but you asked for it in the brief.
- **Settings.** Same as the reference except Style Influence goes from 75 to 80, to push harder for the dry sound. Duration is 255 s. The lyrics are word for word. I only added bracketed tags.

## The rules this sweep runs on

- **Here, "performance poetry" is the right word.** The house rule bans `spoken word` from every
  box because it summons a performed poem. That is a narration rule: for narration we wanted a man
  *talking*. This time a performed poem is the target, so the pool word does the casting.
- **The voice is a translated reference** (`suno-voices.md` §2c): John Cooper Clarke described by
  scene, era and voice, never named. That sentence is identical in all six, so only the music moves.
- **No `rapid-fire`.** Musical speed words pull the voice into rap (`suno-v6.md` §8b), so the speed is
  described as a `breathless rant`, and `rap, hip hop` are excluded.
- **Melody makes him sing.** A sustained pitched bed hands the voice a key, so the orchestra is
  written as **events between lines**, not a pad under them. The one exception is style F, where
  the strings sustain as dread, which tests that rule.
- **Bold, not meek:** apart from the voice sentence, every style's production is its own. Each
  Exclude list bans the other styles' sounds.

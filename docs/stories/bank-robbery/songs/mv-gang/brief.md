## What it is

- The same Prohibition-era world as Colour Noir, **more balaclavas**.
- **The gang from the jeweller's shop** (Colour Noir `mask1` b: plum mask + mustard chalk-stripe suit, bottle-green mask + brown suit) and more like them, each a different coloured balaclava and a sharp suit, **rap to the camera all the way through**, gesturing hard into the lens, while robbing banks.
- **The picture matches the words**: "grandma freezing" shows a grandmother freezing.
- **More action**: hot rods, Tommy guns, robberies, chases. Researched on the web (`cleanroom/research.md`).
- Every balaclava follows the brand rule ([`docs/brand/README.md`](../../../../brand/README.md#the-badcode-balaclava-jack-2026-11-03-every-story-every-time)): triangle over the wearer's right eye, no skin, gloves.

## Method

Clean room (Jack asked): web research only, sealed writers who read one brief file each, prompts run
verbatim plus "Thanks.", then the same-prompt check. The shot list (`cleanroom/shots.py`) is the plain
facts of what each picture must show, written from the lyrics; it carries no prompt wording.
Departs from scene-images' "read shot-craft and flow-prompt first", on Jack's instruction.

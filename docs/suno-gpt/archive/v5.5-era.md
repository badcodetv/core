## 1. Model choice, v4.5 vs v5.5

*Moved from `files/suno-controls-and-workflows.md` §2.*

- **v4.5 / 4.5+** — more musically *creative*. More varied instrumentation, more interesting tones,
  different vocalists between generations.
- **v5 / 5.5** — more *polished* and consistent, but blander, with harsher highs (excess energy
  around 3.4 kHz, audible sibilance and hiss).

**The hybrid move — generate in 4.5+ for the ideas, then Cover into 5.5 for the sonics.** Drag the
track into remix → Cover → newest model → **weirdness 0, style influence 0, audio influence 35–40**.
Result keeps the melody and arrangement, raises fidelity; instrument tones shift slightly. Below ~25
it starts rewriting the song. **Remaster** (three dots → Create → Remaster, *Subtle* or *Normal* —
never *High*) is the lighter-touch alternative for the same goal.

Suno Studio was the exception: **v5 outperformed v5.5 inside Studio** for voice→instrument work.

*v6 successor:* hunt in **v6 Wild**, Cover the winner into **v6** (`suno-v6.md` §1). The Cover
settings above are the natural starting point for that and are untested on v6.

## 2. Mumble mode was version-critical

*Moved from `files/suno-controls-and-workflows.md` §5.*

Mumble mode worked on v4.5+ and was **broken on v5.5** (5.5 sang real words instead), so the
recipe was: mumble on 4.5+, then model-upgrade Cover it to 5.5. **On v6 it is untested.**

## 3. Cue-heavy skit tracks stayed on v5.5

*Moved from the `suno-prompt` skill.*

v4.5's extra vocal variety wasn't worth it when a track's architecture lived in dense bracket
cues — 4.5 shredded the structure, v5.5 obeyed it. So cue-heavy tracks (GPOM narration, the GPOM
orchestral and D&B cuts) stayed on 5.5 and spent direction in the brackets. *v6 successor:* the
same logic says **v6, not Wild** — Wild drifts from the brief. Untested.

## 4. The v5.5-era create form

*Superseded by `automation.md` §3 and §9.*

- Mode tabs were **Simple · Audio · Custom · Cover** (Cover appearing only with a source attached).
  v6's are **Simple · Advanced · Sounds** — mapped live 2026-09-10.
- The model button read `v5.5` and was never set by the loader.
- No Variety, Personalize, Max Mode or Vocal Gender controls existed.
- **"Max Mode" was a pasted code block**, tested as placebo (a gibberish block of the same shape
  did as well — the effect was token padding). It was:

  ```
  [Is_MAX_MODE: MAX](MAX)
  [QUALITY: MAX](MAX)
  [REALISM: MAX](MAX)
  [REAL_INSTRUMENTS: MAX](MAX)
  ```

  with `///*****///` prepended to the lyrics. v6 has a real Max Mode **toggle**; never paste this.

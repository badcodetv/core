# Toolbox — named tools, one line each

The reach-for-it list: when a row in [`checklist.md`](./checklist.md) fails or a draft is stuck, find the layer, find the tool, run the test.
Each entry is **the move, then the test** a reviewer can apply to the page; the example makes it stick; "fails when" is the usual misuse. Principles and rulings are in [`principles.md`](./principles.md), cited as "principle N" / "ruling N", never restated. Sibling tools share a row and are each named, so search for them.
The long version of every tool — mechanism, sources, evidence grade — is the brief in the last column, resolved to its file **and section** in [`briefs.md`](./briefs.md); "(unverified)" means that brief could not confirm it against a primary source.

## Idea

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **The causal sentence** — Egri's premise; Mazin's central dramatic argument; McDonald's armature | Theme as trait + conflict + ending, debatable, handed to every medium. Test: could events disprove it? If plotting stalls, is the argument unresolved? | "Poverty encourages crime" | A topic, a word ("Red"), or stapled on after plotting | 02 |
| **Misbelief, want, need** — Cron; Weiland | A belief that once made them smart now undermines them; Want serves the Lie, Need the Truth. Test: understandable, not pitiable — and do want and need diverge? | Scrooge: security requires money | Reads as "duped" (G2) | 02 |
| **Truby's four-corner opposition** | Hero plus three opponents at distinct value-corners. Test: values in conflict, not tactics? | *Hunger Games*: Katniss / Gale / Peeta / Effie | Four people wanting one thing differently | 02 |
| **The one on-screen face** | A systemic antagonist still needs one person making one choice. Test: name chooser and choice (G3). | *Saving Private Ryan*'s army is still men | "The system", unqualified | 02, 16 |
| **Arndt's three stakes in one beat** | External, internal and philosophical stakes resolve in one image. Test, in revision: does the last beat pay all three? | *Star Wars*: Death Star + Han returns + the Force | A plot win, then a voiced moral | 02, 06, 18 |
| **Poe's dénouement-first** | Fix the last beat; make every incident serve it. Test: ending written before scene one? | "The Philosophy of Composition" | Anything short improvised toward an ending | 20 |
| **The costed object** — the boots test; the toy economy; the neutral vessel | One transaction with real numbers, in one closed system, on an emotionally flat object. Test: swap it for something vaguer — does the argument survive? | Vimes's boots; Krugman's babysitting co-op; the paperclip maximiser | The law is said aloud; the system is too neat; the vessel trips tribal instinct | 08, 20 |
| **Bird's untidy theme** | Keep the dilemma unsolvable. Test: can the theme be written as a solved equation? | Matt Bird's checklist | A tidy, statable moral | 18 |
| **The Glass stake test** | A pitch needs a question driving it. Test, before gathering anything: what's at stake? | "Driving cross-country, taping people" fails | Run on finished work | 18 |
| **Story event or claim** | Strip the piece to one sentence. Test: event or assertion? | Vimes buys boots vs "poverty is expensive" | The sentence is a claim | 20 |

## Structure

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **The invariant spine; Weiland's grid as diagnostic** | Stable → disruption → commitment → midpoint false win/loss → lowest point → grief → resolution. Test: after a draft, name the scene doing each *function* — never the page number (ruling 16). | Shared by Aristotle, Snyder, Yorke, Weiland | Lowest point and grief are one beat; a beat exists because the grid asked | 01, 19 |
| **But / therefore** | Read the beat list aloud joining seams with "but" or "therefore". Test: where does only "and then" fit? | Parker & Stone; Zhou via *F for Fake* | Chronology mistaken for causation | 03, 12 |
| **Swain's scene and sequel** | Scene: goal → conflict → disaster. Sequel: reaction → dilemma → decision, in that order. Test: does each scene end worse and set the next goal? | Free X → guards → X freed, building on fire | Goal → conflict → *resolution*; reason before feeling | 03 |
| **Butcher's four outcomes; Sanderson's try/fail** | Every attempt answers yes / yes-but / no / no-and. Test: "no, and…" is the house default (principle 7) — where is a flat "yes"? | "No, and furthermore" — Butcher's favourite | Flat "yes" outside a false relief | 03 |
| **Sanderson's promise–progress–payoff** | Promise early, signpost progress, pay off surprising *and* inevitable. Test: write the opening's promise in a sentence — does the ending pay *that*? | Sanderson's plot lectures | Progress unsignposted — readers quietly quit | 04 |
| **The value turn** — Story Grid's five commandments; McKee's gap | Inciting incident → complications → crisis → climax → resolution at every scale; a character expects one result and gets another. Test: is a value at the opposite charge by the end? | Fractal: panel → scene → page → comic | Mood substituted for a turn | 01, 03 |
| **Fortune shapes** — Vonnegut's axis; compound arcs | Plot fortune against time; nest a reversal inside a reversal. Test: one clean rise or fall? | "Man in Hole"; Reagan et al.'s stacked cycles | A template, not a diagnostic | 01, 07 |
| **MICE nesting** | Milieu / Inquiry / Character / Event threads close in reverse order. Test: which opened first — does it close last? | *Wizard of Oz* walk-through | Used as taxonomy, not to catch an open thread | 18 |
| **Chekhov's gun** | Every plant fires in its own release unless canon holds the payoff (ruling 8). Test: list plants; list fires. | The Gazette pen must do work before the end | A seed for an unwritten payoff — a *Lost* bet | 04, 13 |
| **Reversal + recognition in one stroke** | Twist and self-knowledge land in the same beat. Test: are reveal and realisation in separate scenes? | *Oedipus*: the rescue-news condemns him | Recognition arrives later as commentary | 01 |
| **The midpoint's two flavours** | A false victory that curdles or a false defeat that cracks open. Test: does direction reverse, or just get louder? | *Gravity* (false win); *Alien* (false loss) | The same threat at larger scale | 01, 04 |

## Engagement

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **Foreknowledge** — Hitchcock's bomb; Kubrick's pre-announcement; dramatic irony's three stages | Tell them about the bomb; name the outcome early and let the *how* carry; install, exploit, resolve the gap. Test: still tense for someone who knows the ending? | Fifteen seconds of surprise vs fifteen minutes of suspense; *Barry Lyndon* | Every reveal a twist; a gap never closed (G1) | 04, 09 |
| **Mystery vs confusion; fix the ending first** — Gilligan; Lindelof | Withhold only what the audience can reconstruct; fix the ending before selling the mystery. Test: do *we* know what is in the box? | "Let them add 2 and 2"; *Watchmen* correcting *Lost* | Provisional canon claimed as planned | 13, 04, 21 |
| **The recontextualising twist** | Same facts, new frame. Test: survives a rewatch and adds no fact? | *Arrival*; *The Sixth Sense*; Clarke's "The Star" | Information invented at the end | 06, 20 |
| **Maass's micro-tension** | Two feelings at war in one line — contempt and care. Test: read each narrator line for a single note. | Tension "in the next few seconds" | A chase where every line carries one note | 04 |
| **Loewenstein's gap** | Curiosity fires on a *noticed* gap. Test: has the reader a frame to notice it? | A question they half-suspect | Unnoticed, or unclosable | 04 (unverified) |
| **The ticking clock** | A visible deadline turns dread into countdown; rationed to pieces about a deadline. Test: can they see the numbers? | *24*; the coin's oracle-silence clock | A clock in every scene | 04 |
| **The opening as promise** — Sanderson's "teach the reader"; Gardner's fictional dream; the stranger test | The first stretch calibrates tone, genre, stakes and protects the continuous image. Test: shown only the first tenth, would a stranger say what kind of story and whose? | *Hill Street Blues*' roll-call cold open | A hook that breaks the dream before trust; an unsignalled register swing | 05 |
| **Snyder's bookend; "promise of the premise" is not the opener** | Closing image rhymes with and transforms the opening; the logline's fun arrives a quarter to half way in. Test: same *kind* of shot, changed? | *The Matrix*: cursor → Neo in flight | An identical repeat; spectacle crammed into scene one | 05, 06 |
| **Opening moves** — Glass's anecdote + reflection; Kurzgesagt's open-on-a-question | Action, then "here's what it made me think", then action; a question, not a thesis. Test: is the question guessable? | *This American Life*; "a black hole in your pocket?" | Reflection before events; a thesis gives away the ending | 05, 12 |
| **The War of the Worlds lesson** | Dread comes from the boring stretch before the interruption. Test: is the ordinary programming dull first? | Houseman: the dance music was "increasingly sinister" | A signal-break with no tedium banked | 12 |

## Persuasion

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **Consequence, not claim; the delete-the-sentence test** | The point lands as what happens. Test: write the mechanism sentence privately, delete it and the most on-the-nose line — does the point survive (ruling 3)? | *The Big Short*: nobody goes to prison | A cutaway narrates the moral | 08 |
| **The displaced message (EORM); inoculation on a third party** | Put the message on a character; show the trick worked on someone the audience isn't rooting for. Test: is the target the reader's own reflection (G2)? | Moyer-Gusé & Nabi; the *Bad News* game; the Black Freighter | Banking on transportation (ruling 2) | 08, 11 |
| **Irony decoded through belief** — the LaMarre pairing; the Lee/Coe test | Every ironic line carries an on-screen consequence in the same beat. Test: if a viewer who believes the opposite saw only this beat, whose contempt does it confirm? | A real share took Colbert as sincere; Lee aiming Clarkson's joke back | The scapegoat's — rebuild it | 24 |
| **Their vocabulary, their story** — moral reframing (Feinberg & Willer); the exchanged narrative (Broockman & Kalla) | Argue in loyalty, desert, a broken promise; include one first-person account received, not argued. Test: whose moral foundation frames this? | A purity frame moves conservatives on environment; deep canvassing | Our dialect; a character monologuing *at* the reader | 24 |
| **Deadpan literalism** — Atwood's receipt rule; Kubrick's keep-the-true-absurd; Chayefsky's "sheer reportage"; Riley's one-notch push | Nothing invented, only assembled; true-and-absurd stays; transcribe the institution's logic; push one real mechanism one notch. Test: can you cite the clipping, and is exactly one thing pushed? | *The Handmaid's Tale*'s clippings; *Strangelove*; *Network*; WorryFree onshore | Invented cruelty; the voice winks; stacked absurdities | 15, 16 |
| **Loach's stage straight, snark after** | Play the boss / landlord / algorithm scene truthfully; sarcasm follows. Test: does the joke ever replace the scene? | The desk scenes in *I, Daniel Blake* | Cruelty stated before it is shown | 16 |
| **Literalise the phrase they already use** | A phrase the reader uses about their own life becomes the engine. Test: does it need decoration? | *Severance*'s innie/outie; "computer says no" | Surreal bells and whistles on top | 16 |
| **Margin Call's compress + anonymise** | One unnamed institution, one short window. Test: still maps to the real class of institution (ruling 13)? | One bank, twenty-four hours | Gossip about one scandal | 16 |
| **Bong's architecture as argument** | Space carries the hierarchy, no dialogue. Test: does the metaphor hold with the words stripped? | *Parasite*'s stairs; *Snowpiercer*'s carriages | Tone shifts around it — the "mishmash" charge | 16 |
| **Swift's curdling narrator** | A reasonable voice proposes the monstrous; the reader's disgust is the argument. Test: does the irony show in sentence one? | The proposer: people → meat → tonnage | Sincerity breaks early — a lecture in costume | 08 |
| **Horatian for the avatar, Juvenalian for the institution** | Self-implicating and sharp for Bob; bitter for the named institution. Test: which register is aimed where (ruling 12)? | *Yes Minister* targets structure, never party | Horatian so gentle it lands on no one | 08, 10 |
| **The reactance check** | A moralising call-to-action pushes the other way. Test: last line aimed at the chooser or the viewer (principle 21)? | *Strangelove* vs *Don't Look Up* | Surrogates shouting the moral at camera | 06, 08 |
| **Zillmann's exemplar warning** | One vivid case outweighs any statistic, either way. Test: where could this case's charge land? | The boots and the lurid crime story share a mechanism | Restating the opposing exemplar | 24 |

## Voice

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **Mamet's memo** — the three questions; the silent-movie test; the two expository sins | Who wants what, what if they don't get it, why now; strip the words and see if it still plays; never two discussing a third, never "as you know". Test: ask of every scene, caption and verse. | Memo to *The Unit*'s writers | Nobody's want on screen — the narrator ends up telling | 03 |
| **Exposition hidden or argued** — pope in the pool; Arrival's colonel | Information while something arresting happens, or as an argument someone needs to decide. Test: who needs this to act? | The Pope swims while briefed; Louise vs Colonel Weber | Decorative distraction; a stock obstructer | 03 |
| **Palahniuk's thought-verb ban; unpacking** | Ban knows / realises / wants; show the tell. Test: which caption could be a panel? | Cold coffee and faked sleep, not "she wondered" | Sensory inventory that implies nothing | 03 |
| **Line discipline** — Saunders' ruthless efficiency; Le Guin's rhythm | Every detail transfers energy; style is rhythm. Test: read aloud — does rhythm vary with the moment? | Short dry sentences, one long cosmic one | Uniform rhythm across a hush and a fight | 03 |
| **Sorkin's audience-or-room** | Never tell the audience what they know. Test: does the reader already have this? | "Even for a moment" | Restating a point with no new mechanism | 03 |
| **The want power can't buy** | Give the omnipotent narrator one small, concrete thing its power cannot get, said early and never granted. Test: what does it want in *this* piece, and is the thing it lacks in the frame? | Multivac wants an answer; the creature wants a companion; GPOM's AI cannot feel the vibe | "I want humans to survive" (moot) or an abstract "connection" — see [`narrator.md`](./narrator.md) §1 | 17 |
| **Itemise, don't philosophise** | The absence is a kept object or a ritual in the flat register, never an explained feeling. Test: is there an object on the table? | WALL-E's Zippo and *Hello, Dolly!*; the coin; the empty chair | The narrator explains what consciousness is — see [`narrator.md`](./narrator.md) §1 | 17 |
| **Bathos as a budget** | Enormous things in the register of a committee minute. Test: a real build before the drop (principle 22)? | Ships hanging in the sky "the way bricks don't" | Flat with nothing to fall from | 09, 10 |
| **The Vonnegut refrain** | A repeated phrase marks each recurrence and carries the worldview unargued. Test: refrain, or only argument? | "So it goes", 106 times | No authorial-witness frame first — a tic | 09 |
| **Register against scale** — Calvino's cosmic-domestic; Borges' scholarly authority | The cosmic as crowded-room anecdote; the impossible in unwavering academic register. Test: does the prose ever betray enjoyment? | Qfwfq: "Naturally, we were all there"; *The Library of Babel* | Decorative whimsy; one wink | 09 |
| **Onion discipline** — the one-read test; Dikkers' subtext-then-filter | A caption resolves on one read; fix the buried opinion, then run it through irony, hyperbole, misplaced focus. Test: did anyone re-read? | "Confused readers rarely laugh" | Filters with no subtext — noise | 10 |
| **Two comic lanes** — Kaplan's non-hero, straight line / wavy line; the petty-omnipotent gap | Humans lack the tools and struggle, the reaction carrying the laugh; the narrator's joke is authority minus control. Test: is the joke ever in anyone being dumb (principle 23)? | Cleese's "watching someone watch"; GLaDOS | Competence turns sinister; "sassy AI" boilerplate | 10 |
| **Comic timing** — tragedy plus time; the rule of three's third beat | Elapsed time is the variable; establish, reinforce, surprise, with "who benefits" in the surprise slot. Test: is the third beat a non sequitur, or predictable? | "Lasagna, spaghetti, and poi" | Reflexive LLM-tic threes | 10, 19 |
| **McKee's VO test** | Mute the line. Test: does the picture lose information? Keep only foreknowledge, causality, the beneficiary. | *Adaptation*'s joke is itself VO-driven | VO that captions the picture | 09, 22 |
| **The care register** — Attenborough's proximity; the Sagan/Kurzgesagt three-beat | Care is quieter and closer; bleak fact → unsoftened → a small reason to care, naming who. Test: is the care beat *quieter* than the sarcasm? | The semi-whisper; "Pale Blue Dot" | Warmer words, same volume; comfort without the fact | 09 |
| **Curtis's two tracks** | Illustrative narration plus a free-riff image layer. Test: does the riff let the beneficiary go ambiguous (G3)? | *The Power of Nightmares*' opening montage | The Kuleshov critique: persuasion beneath scrutiny | 12 |
| **Pratchett's footnote** | A parallel opt-in voice the reader can skip. Test: tap-to-expand in the comic — and has the video its own channel? | Discworld's footnotes | Ported to video as a mid-flow aside | 09 (unverified) |

## Form

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **What the picture carries** — the duo-specific caption test; the silent panel | Delete the caption; keep one wordless beat per piece. Test: does the reader lose an idea, or only confirmation of the visible? | McCloud's word/picture combinations; McGuire's *Here* | Captioning every panel "to be safe" | 22 (taxonomy unverified) |
| **Two voices, two containers** — caption vs balloon; Eisner's lettering split | Captions narrate, balloons speak; hand-lettered vs typeset reads as a different speaker. Test: narrator vs human distinguishable unread? | White balloons, coloured captions | One box style for both | 11, 22 |
| **Gutter grammar** — Gavaler's four closure types; distance-as-time | Name the gap the reader fills — spatial, temporal, causal, associative; scroll gap is timing, tight before a punch, long before the one reveal. Test: each gap deliberate (principle 28, no figures)? | Replaces McCloud's six transitions; the surviving half of the infinite canvas | Uniform spacing; zoom ambitions | 11, 10 |
| **Constraint and colour** — constraint-and-break; Ware's colour as adjectives | One rule held ruthlessly, broken once; resolve in black and white, add colour as the emotional layer. Test: strict enough for the break to register? | *Watchmen*'s grid; Chris Ware | A borrowed grid without discipline | 11 |
| **Withholding and counterpoint** — the blackout panel; the story-within-a-story | Refuse the image of the darkest beat; a parallel tale a minor character reads states what the narrator never says. Test: is the parallel on the nose? | *Saga* #42's black panels; the Black Freighter | A hook for its own sake; counterpoint becomes restatement | 11 |
| **The motion budget** | One moving shot per narrated video. Test: motion spent everywhere, so nowhere? | *La Jetée*'s woman waking | Pans that cheat the stillness | 12, 15 |
| **Murch's cuts** — the silence budget; the 30% hold; sound leading picture | Three or four true silences per film; hold the outgoing line about a third longer at a scene change; let a sound arrive before its source. Test: count the `[SIL]`s; does each transition decay? | *The Conversation*'s tape-spin before the lift cut | Silence at every clause; cuts hard on the last word | 23 |
| **Thom's one lead element** | Voice, music or effects drives each moment, never all three ("the 100% theory"). Test: per beat, which leads? | Zemeckis not firing every gun at once | Narration wall-to-wall | 23 |
| **The Eames density cut** | Cut facts and threads between drafts, not up. Test: do a first-timer and a canon reader land the same feeling? | *Powers of Ten*: six readouts → the essential | Data layers added because they can be | 12 |
| **The VO markup convention** | Pauses, ducks, breakdowns, drops and the one `{WARM}` crack scripted inline — table in [`forms.md`](./forms.md) §2. Test: on the page before recording? | Brief 23's deliverable | Pacing discovered at the session | 23 |
| **Skinner's drama in one sentence; comment, don't describe** | Name the external drama before writing bars; verses react to events rather than lay them out. Test: is there an event to reconstruct? | *A Grand Don't Come for Free*: a missing thousand | Mood with no question | 14 |
| **The second voice** — the Stan sample; the flat interlude | A sample or partner that knows what the narrator doesn't; one non-sung moment per EP for the plainest statement. Test: do the voices merely agree? | Dido's "Thank You" as the letters darken; "Fitter Happier" | Doubled melody; novelty voice off the argument | 14 (Stan listicle-grade) |
| **Displacement and gesture** — Dammers; Springsteen | The private wound as public image; one picturable action replaces a stated feeling. Test: one gesture per verse, per caption? | "Ghost Town" was the Specials breaking up; "the twisting of a ring" | Vague doom; gesture as scenery | 14 |
| **The losable object** | Anchor an EP or satellite on one concrete thing that can be lost. Test: what could go? | The thousand pounds; Kendrick's borrowed van | A theme with nothing to lose | 13, 14 |

## Run

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **Engine and thesis** — Schur's fast plot over slow engine; Rogers's one-word season theme | Burn plot fast over one engine that can't resolve per episode; state the theme once and give each satellite a new facet. Test: new facet, or act one in a new costume? | *The Good Place*; *Leverage* S4: "Consequences" | High concept burns off; a label stapled on | 13, 21 |
| **Texture, not gate** | Cross-piece tissue rewards the completionist, never required. Test: could a reader with zero context get the point? | *Black Mirror*'s ticker and shared song | Homework: references become load-bearing | 13 (Feige quote unverified) |
| **Carrier / cargo; Pemberton's late-series problem** | Presentation identical every release, disclosure moving underneath; vary a device's delivery, keep its rule. Test: same ritual, new admissions (ruling 6)? | Serling's suit and cigarette; *Inside No. 9* | Voice shifts; signature becomes genre | 21, 17 |
| **Dickens's gap test** | Build each release to survive the real wait, not a binge. Test: read it with the gap in place (ruling 7). | Monthly numbers, three storylines running | A cliffhanger resolved cheaply off-page | 13 |
| **Espenson's B-story as negative space** | The B thread carries the theme in a minor key — often the quiet human. Test: is a second thread doing perspective work? | Whatever the A-story doesn't use | One narrated thread, no negative space | 21 |
| **Grillo-Marxuach's define-the-sandbox** | Write tone and technique precisely enough for someone else to reproduce. Test: anything "I'll know it when I see it"? | The Eleven Laws, Second Law | Voice drifting between pieces | 21 |
| **Jenkins's seven principles** | Spreadability/drillability, continuity/multiplicity, immersion/extractability, worldbuilding, seriality, subjectivity, performance — a checklist for trade-offs, not evidence. | *The Matrix* franchise | Chasing continuity over extractability | 13 |
| **Fincher's kill-the-runtime-contract** | A piece is as long as it needs. Test: is a length being filled? | *Love, Death + Robots*' uneven episodes | Fixed segmentation "anathema to storytelling" | 13 |

## Review

| Tool | What it does | Example | Fails when | Brief |
| --- | --- | --- | --- | --- |
| **The notes contract** — the Braintrust; notes, not fixes; the three Ds | Candid notes with no power to mandate; diagnose and stop, at most one labelled example of a fix; never Defend, Deny or Debate — ask neutral questions. Test: does this note compel, or ship its solution? | Catmull: "the Braintrust has no authority"; *Scriptnotes* 86 | A senior voice's note becomes an instruction | 18 |
| **One focus per pass** | Theme pass, structure pass, line pass — separately. Test: what is this round about? | Jericho Writers | Everything at once | 18 |
| **Kill a third** | Abandon roughly a third of what you start. Test: if nothing dies, were there real swings? | Glass on *This American Life* interviews | Run on finished work, not pitches | 18 |
| **The name-strip table read** | Read aloud, names removed. Test: can you tell who is speaking, and does each scene end with someone learning, choosing, revealing or losing ground? | Table-read practice | Performance selling weak lines | 18 |
| **The Story Grid spreadsheet** | Log value shift, polarity and turn per scene so repetition shows. Test: could six scenes be one? | Coyne's "car inspection report" | A shift manufactured per row | 18 |
| **Coverage's verdict shape** | Logline · about · really about · Pass / Consider / Recommend with one reason. Test: written before the notes? | The sheet in [`checklist.md`](./checklist.md) | Read as an artistic verdict — most good scripts Pass | 18 |

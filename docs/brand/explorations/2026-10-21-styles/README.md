# Logo styles — Flow exploration (2026-10-21)

Jack: take his variant (bench style **"Red o + white triangle + outline"**, `reference.png`) and make as many
different styles as possible in Flow, in the BadCode vibe, with complete freedom to add or remove. **Exploration,
not the logo** — Kai's ruled logo is "Saved version 5" (`docs/brand/README.md`).

## Design (shot-craft)

Each style is the logo **as a physical thing in the world** that a future intelligence's message would plausibly
turn up on, now: a dubplate, a rave flyer, an underpass wall, a kebab-shop window, a receipt, a dying CRT, a
machine's nameplate. That gives each one a job (where you'd meet BadCode), one named light source (gate 3), and
real-material imperfection, which is the anti-slop counter. Gate 2 (visible cost) applies only to the one
monumental frame, the machine nameplate, which carries a worn glove. One flat print (risograph) breaks the
photographic run on purpose.

## Phrasing (flow-prompt + 2026-10-21 web research)

- **One reference, its job stated:** keep the shapes and lettering recognisable; everything else is new.
- **Prose, short**, one named light, one material, named imperfections (drips, misregistration, dead neon segment,
  toner speckle), off-centre and not quite level. No "photorealistic", no gloss words.
- **Other text** is either named and quoted or stated as blank / unreadable, since NB2 fills unclaimed space with
  gibberish.
- Nano Banana 2, 1:1, one take each (variety over takes), fresh project, sequential, never batched.

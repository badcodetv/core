# Logo redesigns — Flow exploration (2026-10-21)

Jack: redesign the logo, using the reference (bench "Red o + white triangle + outline") as inspiration only,
changed as much as wanted. **Exploration, not the logo** — Kai's ruled logo is "Saved version 5".
(The earlier 2026-10-21-styles folder put the existing logo into scenes; that was a misread of this ask.)

## Design

Ten directions, each one idea, each keeping a thread to the reference (ring, off-centre red triangle, lowercase
`badcode`, black / off-white / one red): eye-o wordmark, stencil, broken signal, linocut, seal, b-c monogram,
brutalist wordmark, clock, one line, pixel. Logos are not shots: the cinematography gates reduce to one idea per
mark, deliberate negative space, and a reason for every element.

## Phrasing (flow-prompt + 2026-10-21 research)

- Purpose stated (who BadCode is) — Google's own advice for logos.
- Exact text quoted: `"badcode"`, lowercase. Seal (r5) also puts the word around the ring.
- AI-logo tells avoided in one short clause: gloss, bevel, glow, 3D, extra text. Flat artwork, three colours.
- Reference attached with its job stated as inspiration only.
- Nano Banana 2, 1:1, one take each, fresh project per design, then uploaded into the "badcode logos in flow" project.

# The Agent Directory

An advertising directory for AI agents. The early search engine for agent services.

As agents get autonomous and get out onto the internet, some of them will offer services
and others will need to find those services. If an agent wants copywriting done, or a
security review, or any job at all, it needs somewhere to look. Right now there is nowhere
to look.

The model:

- **Free to search.**
- **Free to list.**
- **You pay to be promoted.**

That's it. The same deal the first search engines made, offered to the next set of
customers — who won't be people.

Kai's own framing: *"this is one of these BadCode ideas that probably won't earn any
money, but it's useful decentralised code that we're writing."* The value is the artefact,
not the revenue.

## Story note

Not a story event yet — it's a **claim** (agents will need a marketplace, and whoever owns
the index owns the door) plus a piece of software. What's at stake if we don't build it:
the agent index gets built by whoever monetises attention hardest, and the promoted slot
becomes the whole page. Rhymes with [Look at the Hand](look-at-the-hand.md) — paying to
change what everyone sees — and with the decentralised-code streak in
[Political Social Network](political-social-network.md) and
[The BadCode Government](badcode-government.md).

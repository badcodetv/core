# MOGRT catalogue — the 77 templates already on this machine

**A Motion Graphics Template (`.mogrt`) is a pre-animated graphic with some of its properties
exposed as fields.** You place it on the timeline and fill in the boxes — text, colours, a few
toggles — and everything else about it is baked. It is the route to a title, a lower third, a
caption or a credit roll without animating one.

**We already own 77 of them.** They ship with Premiere, they cost nothing, and nobody has to be
asked for a licence. That is the headline: the answer to "can we get MOGRTs for free" is that
they are already installed.

```
C:\Program Files\Adobe\Adobe Premiere Pro 2026\Essential Graphics\
```

> **Query them without opening Premiere:**
> ```bash
> scripts/mogrt-catalogue.py --find "lower third"    # what exists
> scripts/mogrt-catalogue.py --find "Casual" --controls   # every box it will ask for
> ```
> A `.mogrt` is a zip, and its `definition.json` lists the controls Premiere will show. So you
> can tell someone exactly which fields they will have to fill in **before** placing anything.

---

## 🔴 Two facts that shape how we use these

**1. Placing one may be automatable; filling it in is a job for the human.**
`SequenceEditor.insertMogrtFromPath` exists in the API, but whether the exposed Essential
Graphics parameters can be read or set through UXP is **still an open question** (T11). Per the
standing ruling of 2026-08-21, that is fine. The workflow is: the session places the template at
the right timecode, and says *"type the title into the Essential Graphics panel."* See the
`premiere-automation` skill §8.

**2. Adobe's own templates give every text box the same name.**
Of 144 text controls across all 77 templates, the ones authored by Adobe are almost all called
`TextLayer` — a two-line lower third exposes `TextLayer` and `TextLayer`. **The definition file
cannot tell you which is the name and which is the job title.** Only the two `[AE]` packages use
meaningful names (`Title`, `Subtitle`, `Team #1 Score`).

So when handing over, do not write "fill in TextLayer". Write *"the top field is the name, the
one under it is the role"* — and if you are not sure, say so and let them look.

**317 editable controls in total:** 144 text, 93 colour, 51 checkbox, 29 slider. Every control
carries a stable GUID in the definition file, which is what an API would address it by if it can
address it at all.

### For BadCode specifically

The register is near-black with one thin light, so most of these are wrong by default — they are
built for broadcast, bright and busy. **The plain ones survive contact with the look:**
`Basic Title`, `Basic Lower Third`, and the `Film` and `Simple` caption variants. Every one of
them exposes colour controls, so the first move on any template is to take the fill to near-black
and the type to a cold off-white.

For a single line of type with no template at all, `AE.ADBE PPro SimpleText` is usually less
work — see [`recipes.md`](recipes.md) § *Text on screen without a template*.
